## English

This repository is a beginner-friendly algorithm learning guide written in Markdown. It combines illustrations, code examples, and practice problems to explain data structures, classic algorithms, common patterns, and interview-ready templates. It is suitable for self-study, coding practice, and interview preparation.

### What’s Included
- Complexity analysis
- Arrays and linked lists
- Stacks and queues
- Hash tables
- Trees, heaps, and graphs
- Search and sorting algorithms
- Advanced algorithms such as dynamic programming, greedy methods, and backtracking
- Multi-language implementations
- Exercises with reference answers

### Who Is It For?
- Programming beginners
- Students preparing for algorithm interviews
- Learners who want a structured foundation in algorithms and data structures
- Readers who prefer visual, example-driven learning

### How to Use
1. Read the Markdown files in this repository.
2. Supporting images are stored in the `figures/` directory.
3. It is recommended to study chapter by chapter, from basics to advanced topics.
