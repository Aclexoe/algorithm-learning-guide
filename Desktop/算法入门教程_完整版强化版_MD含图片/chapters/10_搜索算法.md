# 搜索算法

## 什么是搜索算法

搜索算法用于在数据结构中查找特定元素或满足特定条件的元素。搜索算法的效率直接影响程序的性能。

### 搜索算法的分类

1. **线性搜索**：逐个检查元素
2. **二分搜索**：在有序数据中高效搜索
3. **哈希搜索**：使用哈希表快速查找
4. **树搜索**：在树结构中搜索
5. **图搜索**：在图结构中搜索

## 线性搜索

### 基本原理

线性搜索是最简单的搜索算法，从数据结构的第一个元素开始，逐个检查直到找到目标元素或遍历完所有元素。

### 线性搜索实现

```python
def linear_search(arr, target):
    """线性搜索"""
    for i, element in enumerate(arr):
        if element == target:
            return i  # 返回索引
    return -1  # 未找到

# 使用示例
arr = [64, 34, 25, 12, 22, 11, 90]
target = 22
result = linear_search(arr, target)
print(f"元素 {target} 的索引是: {result}")  # 元素 22 的索引是: 4
```

### 线性搜索的复杂度

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)
- **适用场景**：无序数据、小规模数据

### 线性搜索的优化

#### 哨兵线性搜索

```python
def linear_search_sentinel(arr, target):
    """哨兵线性搜索"""
    n = len(arr)
    last = arr[n - 1]  # 保存最后一个元素
    arr[n - 1] = target  # 设置哨兵
    
    i = 0
    while arr[i] != target:
        i += 1
    
    arr[n - 1] = last  # 恢复最后一个元素
    
    if i < n - 1 or arr[n - 1] == target:
        return i
    return -1
```

## 二分搜索

### 基本原理

二分搜索只能在有序数组中使用。它通过比较中间元素与目标值，每次将搜索范围减半，直到找到目标或确定不存在。

### 二分搜索实现

#### 迭代版本

```python
def binary_search(arr, target):
    """二分搜索迭代版本"""
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2
        
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return -1  # 未找到

# 使用示例
arr = [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]
target = 23
result = binary_search(arr, target)
print(f"元素 {target} 的索引是: {result}")  # 元素 23 的索引是: 5
```

#### 递归版本

```python
def binary_search_recursive(arr, target, left, right):
    """二分搜索递归版本"""
    if left > right:
        return -1
    
    mid = (left + right) // 2
    
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binary_search_recursive(arr, target, mid + 1, right)
    else:
        return binary_search_recursive(arr, target, left, mid - 1)

# 使用示例
arr = [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]
target = 23
result = binary_search_recursive(arr, target, 0, len(arr) - 1)
print(f"元素 {target} 的索引是: {result}")
```

### 二分搜索的复杂度

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1) 迭代版本，O(log n) 递归版本
- **适用场景**：有序数组、大规模数据

### 二分搜索的变种

#### 查找第一个出现的元素

```python
def binary_search_first(arr, target):
    """查找第一个出现的元素"""
    left, right = 0, len(arr) - 1
    result = -1
    
    while left <= right:
        mid = (left + right) // 2
        
        if arr[mid] == target:
            result = mid
            right = mid - 1  # 继续在左半部分搜索
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return result
```

def binary_search_last(arr, target):

#### 查找插入位置

```python
def binary_search_insert_position(arr, target):
    """查找插入位置"""
    left, right = 0, len(arr)
    
    while left < right:
        mid = (left + right) // 2
        
        if arr[mid] < target:
            left = mid + 1

```

## 插值搜索

### 基本原理

插值搜索是二分搜索的改进版本，根据目标值在数据分布中的位置来预测其可能的位置。

### 插值搜索实现

```python
def interpolation_search(arr, target):
    """插值搜索"""
    left, right = 0, len(arr) - 1
    
    while left <= right and target >= arr[left] and target <= arr[right]:
        if left == right:
            if arr[left] == target:
                return left
            return -1
        
        # 插值公式
        pos = left + ((target - arr[left]) * (right - left)) // (arr[right] - arr[left])
        
        if arr[pos] == target:
            return pos
        elif arr[pos] < target:
            left = pos + 1
        else:
            right = pos - 1
    
    return -1

# 使用示例
arr = [1, 2, 4, 8, 16, 32, 64, 128, 256, 512]
target = 64
result = interpolation_search(arr, target)
print(f"元素 {target} 的索引是: {result}")
```

### 插值搜索的复杂度

- **时间复杂度**：平均 O(log log n)，最坏 O(n)
- **空间复杂度**：O(1)
- **适用场景**：均匀分布的有序数据

## 哈希搜索

### 基本原理

哈希搜索使用哈希函数将键映射到存储位置，实现 O(1) 时间复杂度的查找。

### 哈希搜索实现

```python
class HashSearch:
    def __init__(self, size=10):
        self.size = size
        self.table = [[] for _ in range(size)]
    
    def _hash(self, key):
        return hash(key) % self.size
    
    def insert(self, key, value):
        """插入键值对"""
        index = self._hash(key)
        
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index][i] = (key, value)
                return
        
        self.table[index].append((key, value))
    
    def search(self, key):
        """搜索键"""
        index = self._hash(key)
        
        for k, v in self.table[index]:
            if k == key:
                return v
        
        return None

# 使用示例
hs = HashSearch()
hs.insert("name", "Alice")
hs.insert("age", 25)
hs.insert("city", "Beijing")

print(hs.search("name"))  # Alice
print(hs.search("age"))   # 25
```

### 哈希搜索的复杂度

- **时间复杂度**：平均 O(1)，最坏 O(n)
- **空间复杂度**：O(n)
- **适用场景**：需要快速查找的场景

## 树搜索

### 二叉搜索树搜索

```python
def bst_search(root, target):
    """二叉搜索树搜索"""
    if not root or root.val == target:
        return root
    
    if target < root.val:
        return bst_search(root.left, target)
    else:
        return bst_search(root.right, target)

# 迭代版本
def bst_search_iterative(root, target):
    """二叉搜索树搜索迭代版本"""
    while root and root.val != target:
        if target < root.val:
            root = root.left
        else:
            root = root.right
    return root
```

### 树搜索的复杂度

- **时间复杂度**：平均 O(log n)，最坏 O(n)
- **空间复杂度**：O(1) 迭代版本，O(log n) 递归版本
- **适用场景**：动态数据、需要频繁插入删除

## 搜索算法比较

| 算法 | 时间复杂度 | 空间复杂度 | 数据要求 | 适用场景 |
|------|------------|------------|----------|----------|
| 线性搜索 | O(n) | O(1) | 无 | 无序数据、小规模 |
| 二分搜索 | O(log n) | O(1) | 有序 | 有序数据、大规模 |
| 插值搜索 | O(log log n) | O(1) | 有序均匀 | 均匀分布数据 |
| 哈希搜索 | O(1) | O(n) | 无 | 需要快速查找 |
| 树搜索 | O(log n) | O(log n) | 无 | 动态数据 |

## 搜索算法的应用

### 应用1：查找重复元素

```python
def find_duplicates(arr):
    """查找重复元素"""
    seen = set()
    duplicates = set()
    
    for element in arr:
        if element in seen:
            duplicates.add(element)
        else:
            seen.add(element)
    
    return list(duplicates)

# 使用示例
arr = [1, 2, 3, 4, 2, 5, 6, 3, 7]
print(find_duplicates(arr))  # [2, 3]
```

### 应用2：查找缺失元素

```python
def find_missing_number(arr, n):
    """查找缺失的数字"""
    # 使用数学公式
    expected_sum = n * (n + 1) // 2
    actual_sum = sum(arr)
    return expected_sum - actual_sum

# 使用示例
arr = [1, 2, 3, 5, 6, 7, 8]
n = 8
print(find_missing_number(arr, n))  # 4
```

### 应用3：查找峰值元素

```python
def find_peak_element(arr):
    """查找峰值元素"""
    left, right = 0, len(arr) - 1
    
    while left < right:
        mid = (left + right) // 2
        
        if arr[mid] > arr[mid + 1]:
            right = mid
        else:
            left = mid + 1
    
    return left

# 使用示例
arr = [1, 3, 20, 4, 1, 0]
peak_index = find_peak_element(arr)

```

### 应用4：搜索旋转排序数组

```python
def search_rotated_array(arr, target):
    """在旋转排序数组中搜索"""
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2
        
        if arr[mid] == target:
            return mid
        
        # 判断哪一半是有序的
        if arr[left] <= arr[mid]:
            # 左半部分有序
            if arr[left] <= target < arr[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:
            # 右半部分有序
            if arr[mid] < target <= arr[right]:
                left = mid + 1
            else:
                right = mid - 1
    
    return -1

# 使用示例
arr = [4, 5, 6, 7, 0, 1, 2]
target = 0
result = search_rotated_array(arr, target)
print(f"元素 {target} 的索引是: {result}")
```

### 应用5：搜索二维矩阵

```python
def search_2d_matrix(matrix, target):
    """在二维矩阵中搜索（每行每列都有序）"""
    if not matrix or not matrix[0]:
        return False
    
    rows, cols = len(matrix), len(matrix[0])
    row, col = 0, cols - 1
    
    while row < rows and col >= 0:
        if matrix[row][col] == target:
            return True
        elif matrix[row][col] > target:
            col -= 1
        else:
            row += 1
    
    return False

# 使用示例
matrix = [
    [1, 4, 7, 11],
    [2, 5, 8, 12],
    [3, 6, 9, 16],
    [10, 13, 14, 17]
]
target = 5
print(search_2d_matrix(matrix, target))  # True
```

## 搜索算法的优化策略

### 1. 预处理

对数据进行预处理（如排序）以支持更高效的搜索算法。

```python
def search_with_preprocessing(arr, targets):
    """预处理后搜索"""
    arr_sorted = sorted(arr)
    results = []
    
    for target in targets:
        result = binary_search(arr_sorted, target)
        results.append(result != -1)
    
    return results
```

### 2. 索引

为数据建立索引以加速搜索。

```python
class IndexedSearch:
    def __init__(self, data):
        self.data = data
        self.index = self._build_index()
    
    def _build_index(self):
        """构建索引"""
        index = {}
        for i, item in enumerate(self.data):
            if item not in index:
                index[item] = []
            index[item].append(i)
        return index
    
    def search(self, target):
        """使用索引搜索"""
        return self.index.get(target, [])
```

### 3. 并行搜索

将搜索任务分配到多个处理器上并行执行。

```python
from concurrent.futures import ThreadPoolExecutor

def parallel_search(arr, targets, num_threads=4):
    """并行搜索"""
    def search_single(target):
        return linear_search(arr, target)
    
    with ThreadPoolExecutor(max_workers=num_threads) as executor:
        results = list(executor.map(search_single, targets))
    
    return results
```

## 总结

搜索算法是查找数据的重要方法：

- **线性搜索**：简单通用，适用于无序数据
- **二分搜索**：高效搜索，要求数据有序
- **插值搜索**：改进的二分搜索，适用于均匀分布数据
- **哈希搜索**：最快搜索，需要额外空间
- **树搜索**：平衡搜索，适用于动态数据

选择合适的搜索算法需要考虑数据特性、搜索频率和性能要求。
