# 复杂度分析

## 为什么需要复杂度分析

在编写算法时，我们需要评估算法的效率。复杂度分析就是一种评估算法性能的方法，它帮助我们：

1. **预测算法性能**：在运行前预估算法的执行效率
2. **比较算法优劣**：选择最适合问题的算法
3. **优化代码**：找出性能瓶颈并改进

复杂度分析主要从两个维度评估算法：
- **时间复杂度**：算法执行时间随输入规模增长的变化趋势
- **空间复杂度**：算法所需存储空间随输入规模增长的变化趋势

## 时间复杂度

### 基本概念

时间复杂度表示算法执行时间与输入规模 n 之间的关系。我们通常使用大 O 表示法来描述时间复杂度。

大 O 表示法关注的是算法的**增长趋势**，而不是具体的执行时间。它忽略了常数项和低阶项，只保留最高阶项。

### 常见时间复杂度

| 复杂度 | 表示 | 特点 | 示例 |
|--------|------|------|------|
| O(1) | 常数时间 | 执行时间不随输入规模变化 | 数组索引访问 |
| O(log n) | 对数时间 | 执行时间随输入规模对数增长 | 二分查找 |
| O(n) | 线性时间 | 执行时间与输入规模成正比 | 线性查找 |
| O(n log n) | 线性对数时间 | 常见于高效排序算法 | 归并排序 |
| O(n²) | 平方时间 | 执行时间与输入规模平方成正比 | 冒泡排序 |
| O(2ⁿ) | 指数时间 | 执行时间随输入规模指数增长 | 递归斐波那契 |
| O(n!) | 阶乘时间 | 执行时间极快增长 | 全排列 |

### 时间复杂度分析示例

#### O(1) - 常数时间

```python
def get_first_element(arr):
    """获取数组第一个元素"""
    if len(arr) > 0:
        return arr[0]
    return None
```

无论数组多大，这个操作都只需要一步，时间复杂度为 O(1)。

#### O(n) - 线性时间

```python
def find_max(arr):
    """查找数组中的最大值"""
    if not arr:
        return None
    
    max_val = arr[0]
    for val in arr:
        if val > max_val:
            max_val = val
    return max_val
```

需要遍历整个数组，时间复杂度为 O(n)。

#### O(n²) - 平方时间

```python
def bubble_sort(arr):
    """冒泡排序"""
    n = len(arr)
    for i in range(n):
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr
```

嵌套循环，外层执行 n 次，内层平均执行 n/2 次，时间复杂度为 O(n²)。

#### O(log n) - 对数时间

```python
def binary_search(arr, target):
    """二分查找"""
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return -1
```

每次查找都将搜索范围减半，时间复杂度为 O(log n)。

### 复杂度计算规则

1. **加法法则**：如果算法由多个顺序执行的步骤组成，总复杂度取最大的那个
   ```python
   def example(n):
       # O(n)
       for i in range(n):
           print(i)
       # O(n²)
       for i in range(n):
           for j in range(n):
               print(i, j)
       # 总复杂度：O(n) + O(n²) = O(n²)
   ```

2. **乘法法则**：如果算法包含嵌套循环，复杂度相乘
   ```python
   def example(n):
       for i in range(n):          # O(n)
           for j in range(n):      # O(n)
               print(i, j)         # O(1)
       # 总复杂度：O(n) × O(n) = O(n²)
   ```

3. **忽略常数**：O(2n) = O(n)，O(3n²) = O(n²)

4. **忽略低阶项**：O(n² + n) = O(n²)，O(n³ + n² + n) = O(n³)

## 空间复杂度

### 基本概念

空间复杂度表示算法执行过程中所需存储空间与输入规模 n 之间的关系。

### 常见空间复杂度

| 复杂度 | 表示 | 特点 | 示例 |
|--------|------|------|------|
| O(1) | 常数空间 | 只使用固定数量的额外空间 | 变量交换 |
| O(n) | 线性空间 | 额外空间与输入规模成正比 | 数组复制 |
| O(n²) | 平方空间 | 额外空间与输入规模平方成正比 | 二维数组 |
| O(log n) | 对数空间 | 递归调用栈的空间 | 二分查找递归 |

### 空间复杂度分析示例

#### O(1) - 常数空间

```python
def swap(a, b):
    """交换两个变量的值"""
    temp = a
    a = b
    b = temp
    return a, b
```

只使用了固定数量的变量，空间复杂度为 O(1)。

#### O(n) - 线性空间

```python
def reverse_array(arr):
    """反转数组"""
    n = len(arr)
    reversed_arr = [0] * n  # 需要额外的 n 个空间
    for i in range(n):
        reversed_arr[i] = arr[n - 1 - i]
    return reversed_arr
```

创建了一个与原数组大小相同的新数组，空间复杂度为 O(n)。

#### O(n) - 递归空间

```python
def factorial(n):
    """递归计算阶乘"""
    if n <= 1:
        return 1
    return n * factorial(n - 1)
```

递归深度为 n，每次调用都需要栈空间，空间复杂度为 O(n)。

## 时间与空间的权衡

在实际应用中，我们经常需要在时间和空间之间进行权衡：

### 以空间换时间

```python
# 方法1：时间复杂度 O(n)，空间复杂度 O(1)
def fibonacci_1(n):
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b

# 方法2：时间复杂度 O(1)，空间复杂度 O(n)
def fibonacci_2(n):
    if n <= 1:
        return n
    fib = [0] * (n + 1)
    fib[1] = 1
    for i in range(2, n + 1):
        fib[i] = fib[i - 1] + fib[i - 2]
    return fib[n]
```

方法1节省空间但需要计算，方法2预先计算存储但占用更多空间。

### 以时间换空间

在内存受限的情况下，我们可以选择牺牲时间来节省空间。

## 复杂度分析的实际应用

### 1. 选择合适的算法

```python
# 小数据量：简单排序
def sort_small_array(arr):
    if len(arr) < 100:
        return bubble_sort(arr)  # O(n²)
    else:
        return merge_sort(arr)   # O(n log n)
```

### 2. 优化代码性能

```python
# 优化前：O(n²)
def find_duplicates_slow(arr):
    duplicates = []
    for i in range(len(arr)):
        for j in range(i + 1, len(arr)):
            if arr[i] == arr[j] and arr[i] not in duplicates:
                duplicates.append(arr[i])
    return duplicates

# 优化后：O(n)
def find_duplicates_fast(arr):
    seen = set()
    duplicates = set()
    for item in arr:
        if item in seen:
            duplicates.add(item)
        else:
            seen.add(item)
    return list(duplicates)
```

### 3. 预估系统性能

通过复杂度分析，我们可以预估系统在不同数据规模下的表现。

## 常见误区

1. **忽略最坏情况**：应该考虑最坏情况下的复杂度
2. **过度优化**：不是所有地方都需要最优复杂度
3. **只关注时间**：空间复杂度同样重要
4. **过早优化**：先确保正确性，再考虑性能

## 总结

复杂度分析是算法设计和优化的重要工具：

- **时间复杂度**评估算法的执行效率
- **空间复杂度**评估算法的内存使用
- **大 O 表示法**提供了一种标准化的描述方法
- **权衡考虑**在实际应用中平衡时间和空间

掌握复杂度分析能够帮助你：
- 设计更高效的算法
- 做出更好的技术选择
- 编写出更优质的代码
