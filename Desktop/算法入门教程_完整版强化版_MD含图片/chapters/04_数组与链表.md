# 数组与链表

## 数组

### 什么是数组

数组是最基本的数据结构，它是一组相同类型数据的集合，存储在连续的内存空间中。

### 数组的特性

1. **连续内存**：元素在内存中连续存储
2. **固定大小**：创建时需要指定大小（静态数组）
3. **随机访问**：可以通过索引快速访问任意元素
4. **相同类型**：所有元素必须是相同类型

### 数组的基本操作

#### 访问元素

```python
def access_element(arr, index):
    """访问数组中指定索引的元素"""
    if 0 <= index < len(arr):
        return arr[index]
    raise IndexError("索引越界")

# 使用示例
my_array = [10, 20, 30, 40, 50]
print(access_element(my_array, 2))  # 输出: 30
```

时间复杂度：O(1)

#### 插入元素

```python
def insert_element(arr, index, value):
    """在指定位置插入元素"""
    if index < 0 or index > len(arr):
        raise IndexError("索引越界")
    arr.insert(index, value)
    return arr

# 使用示例
my_array = [10, 20, 30, 40, 50]
print(insert_element(my_array, 2, 25))  # 输出: [10, 20, 25, 30, 40, 50]
```

时间复杂度：O(n) - 需要移动后续元素

#### 删除元素

```python
def delete_element(arr, index):
    """删除指定位置的元素"""
    if index < 0 or index >= len(arr):
        raise IndexError("索引越界")
    arr.pop(index)
    return arr

# 使用示例
my_array = [10, 20, 30, 40, 50]
print(delete_element(my_array, 2))  # 输出: [10, 20, 40, 50]
```

时间复杂度：O(n) - 需要移动后续元素

#### 查找元素

```python
def find_element(arr, value):
    """查找元素在数组中的位置"""
    for i, item in enumerate(arr):
        if item == value:
            return i
    return -1  # 未找到

# 使用示例
my_array = [10, 20, 30, 40, 50]
print(find_element(my_array, 30))  # 输出: 2
print(find_element(my_array, 35))  # 输出: -1
```

时间复杂度：O(n) - 线性查找

### 数组的优缺点

#### 优点

1. **快速访问**：O(1) 时间复杂度的随机访问
2. **内存连续**：缓存友好，提高访问效率
3. **简单易用**：实现简单，易于理解

#### 缺点

1. **大小固定**：静态数组大小不可变
2. **插入删除慢**：需要移动元素，时间复杂度 O(n)
3. **内存浪费**：可能分配过多内存

### Python 中的数组

Python 的列表实际上是动态数组：

```python
# Python 列表（动态数组）
my_list = [1, 2, 3, 4, 5]

# 动态扩容
my_list.append(6)  # 自动扩容
print(my_list)  # [1, 2, 3, 4, 5, 6]

# 列表操作
my_list.insert(2, 10)  # 插入
my_list.remove(4)      # 删除
print(my_list[1])      # 访问
```

### 数组的应用场景

1. **需要快速随机访问**：如矩阵运算
2. **数据量相对固定**：如一周的温度数据
3. **需要内存连续存储**：如图像处理

```python
# 应用1：矩阵运算
def matrix_add(matrix1, matrix2):
    """矩阵加法"""
    rows = len(matrix1)
    cols = len(matrix1[0])
    result = [[0 for _ in range(cols)] for _ in range(rows)]
    
    for i in range(rows):
        for j in range(cols):
            result[i][j] = matrix1[i][j] + matrix2[i][j]
    
    return result

# 应用2：滑动窗口
def sliding_window(arr, window_size):
    """滑动窗口最大值"""
    if window_size > len(arr):
        return []
    
    result = []
    for i in range(len(arr) - window_size + 1):
        window = arr[i:i + window_size]
        result.append(max(window))
    
    return result
```

## 链表

### 什么是链表

链表是一种线性数据结构，通过指针将一组分散的内存块连接起来。每个节点包含数据和指向下一个节点的指针。

### 链表的特性

1. **非连续内存**：节点可以分散在内存中
2. **动态大小**：可以动态添加或删除节点
3. **顺序访问**：必须从头节点开始遍历
4. **指针连接**：通过指针连接各个节点

### 链表的类型

#### 单向链表

每个节点只包含指向下一个节点的指针。

```python
class ListNode:
    def __init__(self, data=0):
        self.data = data
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None
    
    def append(self, data):
        """在链表末尾添加节点"""
        new_node = ListNode(data)
        if not self.head:
            self.head = new_node
            return
        
        current = self.head
        while current.next:
            current = current.next
        current.next = new_node
    
    def display(self):
        """显示链表内容"""
        current = self.head
        while current:
            print(current.data, end=" -> ")
            current = current.next
        print("None")
    
    def find(self, data):
        """查找节点"""
        current = self.head
        while current:
            if current.data == data:
                return current
            current = current.next
        return None
    
    def delete(self, data):
        """删除节点"""
        if not self.head:
            return
        
        if self.head.data == data:
            self.head = self.head.next
            return
        
        current = self.head
        while current.next:
            if current.next.data == data:
                current.next = current.next.next
                return
            current = current.next
```

#### 双向链表

每个节点包含指向前驱节点和后继节点的指针。

```python
class DoublyListNode:
    def __init__(self, data=0):
        self.data = data
        self.prev = None
        self.next = None

class DoublyLinkedList:
    def __init__(self):
        self.head = None
        self.tail = None
    
    def append(self, data):
        """在链表末尾添加节点"""
        new_node = DoublyListNode(data)
        if not self.head:
            self.head = new_node
            self.tail = new_node
            return
        
        self.tail.next = new_node
        new_node.prev = self.tail
        self.tail = new_node
    
    def display_forward(self):
        """正向显示链表"""
        current = self.head
        while current:
            print(current.data, end=" -> ")
            current = current.next
        print("None")
    
    def display_backward(self):
        """反向显示链表"""
        current = self.tail
        while current:
            print(current.data, end=" -> ")
            current = current.prev
        print("None")
```

### 链表的基本操作

#### 访问元素

```python
def access_node(head, index):
    """访问指定位置的节点"""
    current = head
    count = 0
    
    while current:
        if count == index:
            return current.data
        current = current.next
        count += 1
    
    raise IndexError("索引越界")
```

时间复杂度：O(n)

#### 插入节点

```python
def insert_node(head, index, data):
    """在指定位置插入节点"""
    new_node = ListNode(data)
    
    if index == 0:
        new_node.next = head
        return new_node
    
    current = head
    count = 0
    
    while current and count < index - 1:
        current = current.next
        count += 1
    
    if not current:
        raise IndexError("索引越界")
    
    new_node.next = current.next
    current.next = new_node
    
    return head
```

时间复杂度：O(n)

#### 删除节点

```python
def delete_node(head, data):
    """删除指定数据的节点"""
    if not head:
        return None
    
    if head.data == data:
        return head.next
    
    current = head
    while current.next:
        if current.next.data == data:
            current.next = current.next.next
            return head
        current = current.next
    
    return head
```

时间复杂度：O(n)

### 链表的优缺点

#### 优点

1. **动态大小**：可以动态添加或删除节点
2. **插入删除快**：已知位置时插入删除为 O(1)
3. **内存灵活**：不需要连续内存空间

#### 缺点

1. **访问慢**：随机访问需要 O(n) 时间
2. **额外空间**：每个节点需要额外的指针空间
3. **缓存不友好**：非连续存储，缓存命中率低

### 链表的应用场景

1. **频繁插入删除**：如文本编辑器
2. **动态数据集合**：如内存管理
3. **实现其他数据结构**：如栈、队列、图

```python
# 应用1：实现栈
class LinkedListStack:
    def __init__(self):
        self.top = None
    
    def push(self, data):
        new_node = ListNode(data)
        new_node.next = self.top
        self.top = new_node
    
    def pop(self):
        if not self.top:
            raise IndexError("栈为空")
        data = self.top.data
        self.top = self.top.next
        return data
    
    def is_empty(self):
        return self.top is None

# 应用2：实现队列
class LinkedListQueue:
    def __init__(self):
        self.front = None
        self.rear = None
    
    def enqueue(self, data):
        new_node = ListNode(data)
        if not self.rear:
            self.front = new_node
            self.rear = new_node
            return
        self.rear.next = new_node
        self.rear = new_node
    
    def dequeue(self):
        if not self.front:
            raise IndexError("队列为空")
        data = self.front.data
        self.front = self.front.next
        if not self.front:
            self.rear = None
        return data
```

## 数组 vs 链表

### 性能对比

| 操作 | 数组 | 链表 |
|------|------|------|
| 随机访问 | O(1) | O(n) |
| 头部插入 | O(n) | O(1) |
| 尾部插入 | O(1) | O(n) |
| 中间插入 | O(n) | O(n) |
| 头部删除 | O(n) | O(1) |
| 尾部删除 | O(1) | O(n) |
| 中间删除 | O(n) | O(n) |
| 空间效率 | 高 | 较低（需要指针） |

### 选择建议

#### 选择数组的情况

1. 需要频繁随机访问
2. 数据量相对固定
3. 对内存空间敏感
4. 需要缓存友好的访问模式

#### 选择链表的情况

1. 频繁在头部插入删除
2. 数据量动态变化
3. 不需要随机访问
4. 内存空间分散

### 实际应用示例

#### 示例1：LRU缓存（双向链表 + 哈希表）

```python
class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = {}
        self.head = DoublyListNode()
        self.tail = DoublyListNode()
        self.head.next = self.tail
        self.tail.prev = self.head
    
    def get(self, key):
        if key in self.cache:
            node = self.cache[key]
            self._remove(node)
            self._add(node)
            return node.value
        return -1
    
    def put(self, key, value):
        if key in self.cache:
            self._remove(self.cache[key])
        
        node = DoublyListNode(key, value)
        self.cache[key] = node
        self._add(node)
        
        if len(self.cache) > self.capacity:
            old_node = self.head.next
            self._remove(old_node)
            del self.cache[old_node.key]
    
    def _remove(self, node):
        prev_node = node.prev
        next_node = node.next
        prev_node.next = next_node
        next_node.prev = prev_node
    
    def _add(self, node):
        prev_node = self.tail.prev
        prev_node.next = node
        node.prev = prev_node
        node.next = self.tail
        self.tail.prev = node
```

#### 示例2：合并有序链表

```python
def merge_sorted_lists(l1, l2):
    """合并两个有序链表"""
    dummy = ListNode()
    current = dummy
    
    while l1 and l2:
        if l1.data <= l2.data:
            current.next = l1
            l1 = l1.next
        else:
            current.next = l2
            l2 = l2.next
        current = current.next
    
    current.next = l1 if l1 else l2
    return dummy.next
```

## 总结

数组和链表是最基础的线性数据结构：

- **数组**：连续内存，快速访问，适合静态数据
- **链表**：分散内存，灵活插入，适合动态数据
- **选择依据**：根据操作需求和性能要求选择
- **实际应用**：两者都有广泛的应用场景
