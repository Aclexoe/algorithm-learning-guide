# 排序算法

## 什么是排序算法

排序算法是将一组数据按照特定顺序（升序或降序）重新排列的算法。排序是计算机科学中最基本也是最重要的操作之一。

### 排序算法的分类

1. **比较排序**：通过比较元素大小进行排序
2. **非比较排序**：不通过比较元素大小进行排序
3. **内部排序**：所有数据都在内存中
4. **外部排序**：数据量太大，需要使用外部存储

### 排序算法的评估标准

- **时间复杂度**：算法执行时间
- **空间复杂度**：算法所需额外空间
- **稳定性**：相等元素的相对位置是否保持不变
- **适应性**：对部分有序数据的处理能力

## 简单排序算法

### 冒泡排序

#### 基本原理

冒泡排序通过重复遍历数组，比较相邻元素并交换位置，使较大的元素逐渐"冒泡"到数组末尾。

#### 冒泡排序实现

```python
def bubble_sort(arr):
    """冒泡排序"""
    n = len(arr)
    
    for i in range(n):
        # 标记本轮是否发生交换
        swapped = False
        
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        
        # 如果没有发生交换，说明已经有序
        if not swapped:
            break
    
    return arr

# 使用示例
arr = [64, 34, 25, 12, 22, 11, 90]
print("排序前:", arr)
bubble_sort(arr)
print("排序后:", arr)
```

#### 冒泡排序的复杂度

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)
- **稳定性**：稳定
- **适用场景**：小规模数据、教学演示

### 选择排序

#### 基本原理

选择排序每次从未排序部分选择最小元素，放到已排序部分的末尾。

#### 选择排序实现

```python
def selection_sort(arr):
    """选择排序"""
    n = len(arr)
    
    for i in range(n):
        # 找到未排序部分的最小元素
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        
        # 交换最小元素到当前位置
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    
    return arr

# 使用示例
arr = [64, 34, 25, 12, 22, 11, 90]
print("排序前:", arr)
selection_sort(arr)
print("排序后:", arr)
```

#### 选择排序的复杂度

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)
- **稳定性**：不稳定
- **适用场景**：小规模数据、交换成本高的情况

### 插入排序

#### 基本原理

插入排序将数组分为已排序和未排序两部分，每次将未排序部分的第一个元素插入到已排序部分的正确位置。

#### 插入排序实现

```python
def insertion_sort(arr):
    """插入排序"""
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        
        # 将大于key的元素向后移动
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        
        arr[j + 1] = key
    
    return arr

# 使用示例
arr = [64, 34, 25, 12, 22, 11, 90]
print("排序前:", arr)
insertion_sort(arr)
print("排序后:", arr)
```

#### 插入排序的复杂度

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)
- **稳定性**：稳定
- **适用场景**：小规模数据、部分有序数据

## 高级排序算法

### 归并排序

#### 基本原理

归并排序采用分治策略，将数组分成两半，分别排序后合并。

#### 归并排序实现

```python
def merge_sort(arr):
    """归并排序"""
    if len(arr) <= 1:
        return arr
    
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    
    return merge(left, right)

def merge(left, right):
    """合并两个有序数组"""
    result = []
    i = j = 0
    
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    
    result.extend(left[i:])
    result.extend(right[j:])
    
    return result

# 使用示例
arr = [64, 34, 25, 12, 22, 11, 90]
print("排序前:", arr)
sorted_arr = merge_sort(arr)
print("排序后:", sorted_arr)
```

#### 归并排序的复杂度

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)
- **稳定性**：稳定
- **适用场景**：大规模数据、需要稳定排序

### 快速排序

#### 基本原理

快速排序选择一个基准元素，将数组分为小于基准和大于基准的两部分，递归排序。

#### 快速排序实现

```python
def quick_sort(arr):
    """快速排序"""
    if len(arr) <= 1:
        return arr
    
    pivot = arr[len(arr) // 2]  # 选择中间元素作为基准
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    
    return quick_sort(left) + middle + quick_sort(right)

# 原地版本
def quick_sort_inplace(arr, low, high):
    """快速排序原地版本"""
    if low < high:
        pi = partition(arr, low, high)
        quick_sort_inplace(arr, low, pi - 1)
        quick_sort_inplace(arr, pi + 1, high)

def partition(arr, low, high):
    """分区函数"""
    pivot = arr[high]
    i = low - 1
    
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1

# 使用示例
arr = [64, 34, 25, 12, 22, 11, 90]
print("排序前:", arr)
sorted_arr = quick_sort(arr)
print("排序后:", sorted_arr)
```

#### 快速排序的复杂度

- **时间复杂度**：平均 O(n log n)，最坏 O(n²)
- **空间复杂度**：O(log n) 递归栈
- **稳定性**：不稳定
- **适用场景**：大规模数据、平均性能最优

### 堆排序

#### 基本原理

堆排序利用堆的性质，先构建最大堆，然后逐个提取最大元素。

#### 堆排序实现

```python
def heap_sort(arr):
    """堆排序"""
    n = len(arr)
    
    # 构建最大堆
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)
    
    # 逐个提取元素
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]
        heapify(arr, i, 0)
    
    return arr

def heapify(arr, n, i):
    """堆化操作"""
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2
    
    if left < n and arr[left] > arr[largest]:
        largest = left
    
    if right < n and arr[right] > arr[largest]:
        largest = right
    
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)

# 使用示例
arr = [64, 34, 25, 12, 22, 11, 90]
print("排序前:", arr)
heap_sort(arr)
print("排序后:", arr)
```

#### 堆排序的复杂度

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)
- **稳定性**：不稳定
- **适用场景**：需要原地排序、空间受限

## 非比较排序算法

### 计数排序

#### 基本原理

计数排序统计每个元素出现的次数，根据统计结果重新排列元素。

#### 计数排序实现

```python
def counting_sort(arr):
    """计数排序"""
    if not arr:
        return []
    
    max_val = max(arr)
    min_val = min(arr)
    range_of_elements = max_val - min_val + 1
    
    # 创建计数数组
    count = [0] * range_of_elements
    
    # 统计每个元素出现的次数
    for num in arr:
        count[num - min_val] += 1
    
    # 重建排序后的数组
    sorted_arr = []
    for i in range(range_of_elements):
        sorted_arr.extend([i + min_val] * count[i])
    
    return sorted_arr

# 使用示例
arr = [64, 34, 25, 12, 22, 11, 90]
print("排序前:", arr)
sorted_arr = counting_sort(arr)
print("排序后:", sorted_arr)
```

#### 计数排序的复杂度

- **时间复杂度**：O(n + k)，k 是数据范围
- **空间复杂度**：O(k)
- **稳定性**：稳定
- **适用场景**：整数排序、数据范围有限

### 桶排序

#### 基本原理

桶排序将数据分到有限数量的桶中，每个桶单独排序，最后合并。

#### 桶排序实现

```python
def bucket_sort(arr):
    """桶排序"""
    if not arr:
        return []
    
    # 确定桶的数量
    num_buckets = len(arr)
    max_val = max(arr)
    min_val = min(arr)
    
    # 创建桶
    buckets = [[] for _ in range(num_buckets)]
    
    # 将元素分配到桶中
    for num in arr:
        index = int((num - min_val) / (max_val - min_val + 1) * num_buckets)
        buckets[index].append(num)
    
    # 对每个桶进行排序
    for bucket in buckets:
        bucket.sort()
    
    # 合并桶
    sorted_arr = []
    for bucket in buckets:
        sorted_arr.extend(bucket)
    
    return sorted_arr

# 使用示例
arr = [64, 34, 25, 12, 22, 11, 90]
print("排序前:", arr)
sorted_arr = bucket_sort(arr)
print("排序后:", sorted_arr)
```

#### 桶排序的复杂度

- **时间复杂度**：平均 O(n + k)，最坏 O(n²)
- **空间复杂度**：O(n + k)
- **稳定性**：稳定
- **适用场景**：数据均匀分布

### 基数排序

#### 基本原理

基数排序按照数的位数进行排序，从最低位到最高位逐位排序。

#### 基数排序实现

```python
def radix_sort(arr):
    """基数排序"""
    if not arr:
        return []
    
    # 找到最大数以确定位数
    max_val = max(arr)
    exp = 1
    
    while max_val // exp > 0:
        counting_sort_by_digit(arr, exp)
        exp *= 10
    
    return arr

def counting_sort_by_digit(arr, exp):
    """按位数进行计数排序"""
    n = len(arr)
    output = [0] * n
    count = [0] * 10
    
    # 统计当前位数的出现次数
    for i in range(n):
        index = (arr[i] // exp) % 10
        count[index] += 1
    
    # 计算累积计数
    for i in range(1, 10):
        count[i] += count[i - 1]
    
    # 构建输出数组
    for i in range(n - 1, -1, -1):
        index = (arr[i] // exp) % 10
        output[count[index] - 1] = arr[i]
        count[index] -= 1
    
    # 复制到原数组
    for i in range(n):
        arr[i] = output[i]

# 使用示例
arr = [170, 45, 75, 90, 802, 24, 2, 66]
print("排序前:", arr)
radix_sort(arr)
print("排序后:", arr)
```

#### 基数排序的复杂度

- **时间复杂度**：O(d × (n + k))，d 是位数，k 是基数
- **空间复杂度**：O(n + k)
- **稳定性**：稳定
- **适用场景**：整数排序、固定长度数据

## 排序算法比较

| 算法 | 时间复杂度 | 空间复杂度 | 稳定性 | 适用场景 |

## 排序算法的应用

### 应用1：查找中位数

```python
def find_median(arr):
    """查找中位数"""
    sorted_arr = sorted(arr)
    n = len(sorted_arr)
    
    if n % 2 == 1:
        return sorted_arr[n // 2]
    else:
        return (sorted_arr[n // 2 - 1] + sorted_arr[n // 2]) / 2

# 使用示例
arr = [3, 1, 4, 1, 5, 9, 2, 6]
print(f"中位数是: {find_median(arr)}")
```

### 应用2：查找第K大元素

```python
def find_kth_largest(arr, k):
    """查找第K大元素"""
    # 使用快速选择算法
    def quick_select(left, right, k_smallest):
        if left == right:
            return arr[left]
        
        pivot_index = partition(left, right)
        
        if k_smallest == pivot_index:
            return arr[k_smallest]
        elif k_smallest < pivot_index:
            return quick_select(left, pivot_index - 1, k_smallest)
        else:
            return quick_select(pivot_index + 1, right, k_smallest)
    
    def partition(left, right):
        pivot = arr[right]
        i = left
        
        for j in range(left, right):
            if arr[j] <= pivot:
                arr[i], arr[j] = arr[j], arr[i]
                i += 1
        
        arr[i], arr[right] = arr[right], arr[i]
        return i
    
    return quick_select(0, len(arr) - 1, len(arr) - k)

# 使用示例
arr = [3, 2, 1, 5, 6, 4]
k = 2
print(f"第 {k} 大的元素是: {find_kth_largest(arr, k)}")
```

def has_duplicates(arr):
    """检测是否有重复元素"""
    sorted_arr = sorted(arr)
    
    for i in range(1, len(sorted_arr)):
        if sorted_arr[i] == sorted_arr[i - 1]:
            return True
    
    return False

### 应用5：区间重叠检测

```python
def merge_intervals(intervals):
    """合并重叠区间"""
    if not intervals:
        return []
    
    # 按起始时间排序
    intervals.sort(key=lambda x: x[0])
    
    merged = [intervals[0]]
    
    for interval in intervals[1:]:
        if interval[0] <= merged[-1][1]:
            # 有重叠，合并区间
            merged[-1][1] = max(merged[-1][1], interval[1])
        else:
            # 无重叠，添加新区间
            merged.append(interval)
    
    return merged

# 使用示例
intervals = [[1, 3], [2, 6], [8, 10], [15, 18]]
print(merge_intervals(intervals))  # [[1, 6], [8, 10], [15, 18]]
```

## 排序算法的优化

### 1. 混合排序

结合多种排序算法的优点，根据数据特征选择合适的算法。

```python
def hybrid_sort(arr):
    """混合排序：小数组用插入排序，大数组用快速排序"""
    if len(arr) <= 10:
        return insertion_sort(arr)
    else:
        return quick_sort(arr)
```

### 2. 自适应排序

根据数据的有序程度调整算法行为。

```python
def adaptive_insertion_sort(arr):
    """自适应插入排序"""
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        
        # 如果已经有序，提前终止
        if arr[j] <= key:
            continue
        
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        
        arr[j + 1] = key
    
    return arr
```

### 3. 并行排序

利用多核处理器并行执行排序。

```python
from concurrent.futures import ThreadPoolExecutor

def parallel_merge_sort(arr):
    """并行归并排序"""
    if len(arr) <= 1:
        return arr
    
    mid = len(arr) // 2
    
    with ThreadPoolExecutor(max_workers=2) as executor:
        left_future = executor.submit(parallel_merge_sort, arr[:mid])
        right_future = executor.submit(parallel_merge_sort, arr[mid:])
        
        left = left_future.result()
        right = right_future.result()
    
    return merge(left, right)
```
