# 哈希表

## 什么是哈希表

哈希表（Hash Table）是一种基于键值对（Key-Value）存储的数据结构，通过哈希函数将键映射到存储位置，实现快速的数据查找、插入和删除。

### 哈希表的特性

1. **快速查找**：平均时间复杂度为 O(1)
2. **键值对存储**：通过键直接访问对应的值
3. **无序存储**：数据在表中没有特定的顺序
4. **唯一键**：每个键必须是唯一的

## 哈希函数

### 哈希函数的作用

哈希函数将输入的键转换为数组索引，决定数据在哈希表中的存储位置。

### 理想的哈希函数

1. **确定性**：相同的输入总是产生相同的输出
2. **均匀分布**：将键均匀分布到所有可能的索引
3. **高效计算**：计算速度快
4. **低冲突率**：尽量减少哈希冲突

### 简单的哈希函数

```python
def simple_hash(key, size):
    """简单的哈希函数"""
    if isinstance(key, int):
        return key % size
    elif isinstance(key, str):
        hash_value = 0
        for char in key:
            hash_value += ord(char)
        return hash_value % size
    else:
        return hash(key) % size

# 使用示例
print(simple_hash(42, 10))      # 2
print(simple_hash("hello", 10))  # 取决于字符串的哈希值
print(simple_hash(100, 10))     # 0
```

## 哈希冲突

### 什么是哈希冲突

当两个不同的键通过哈希函数映射到相同的索引时，就发生了哈希冲突。

### 冲突解决方法

#### 1. 链地址法（Separate Chaining）

每个哈希表位置维护一个链表，冲突的元素都存储在同一个链表中。

```python
class HashTableChaining:
    def __init__(self, size=10):
        self.size = size
        self.table = [[] for _ in range(size)]
    
    def _hash(self, key):
        return hash(key) % self.size
    
    def put(self, key, value):
        """插入键值对"""
        index = self._hash(key)
        
        # 检查键是否已存在
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index][i] = (key, value)
                return
        
        # 键不存在，添加新键值对
        self.table[index].append((key, value))
    
    def get(self, key):
        """获取键对应的值"""
        index = self._hash(key)
        
        for k, v in self.table[index]:
            if k == key:
                return v
        
        raise KeyError(f"键 '{key}' 不存在")
    
    def remove(self, key):
        """删除键值对"""
        index = self._hash(key)
        
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index].pop(i)
                return
        
        raise KeyError(f"键 '{key}' 不存在")
    
    def display(self):
        """显示哈希表内容"""
        for i, bucket in enumerate(self.table):
            print(f"索引 {i}: {bucket}")
```

#### 2. 开放寻址法（Open Addressing）

当发生冲突时，寻找下一个可用的位置。

```python
class HashTableOpenAddressing:
    def __init__(self, size=10):
        self.size = size
        self.keys = [None] * size
        self.values = [None] * size
    
    def _hash(self, key):
        return hash(key) % self.size
    
    def _probe(self, key):
        """线性探测"""
        index = self._hash(key)
        i = 0
        while self.keys[index] is not None and self.keys[index] != key:
            index = (index + 1) % self.size
            i += 1
            if i >= self.size:
                raise Exception("哈希表已满")
        return index
    
    def put(self, key, value):
        """插入键值对"""
        index = self._probe(key)
        self.keys[index] = key
        self.values[index] = value
    
    def get(self, key):
        """获取键对应的值"""
        index = self._probe(key)
        if self.keys[index] == key:
            return self.values[index]
        raise KeyError(f"键 '{key}' 不存在")
    
    def remove(self, key):
        """删除键值对"""
        index = self._probe(key)
        if self.keys[index] == key:
            self.keys[index] = None
            self.values[index] = None
        else:
            raise KeyError(f"键 '{key}' 不存在")
```

## 哈希表的基本操作

### 插入（Put）

```python
def put(hash_table, key, value):
    """插入键值对"""
    index = hash_function(key, hash_table.size)
    hash_table.table[index] = (key, value)
```

平均时间复杂度：O(1)

### 查找（Get）

```python
def get(hash_table, key):
    """获取键对应的值"""
    index = hash_function(key, hash_table.size)
    if hash_table.table[index] and hash_table.table[index][0] == key:
        return hash_table.table[index][1]
    return None
```

平均时间复杂度：O(1)

### 删除（Remove）

```python
def remove(hash_table, key):
    """删除键值对"""
    index = hash_function(key, hash_table.size)
    if hash_table.table[index] and hash_table.table[index][0] == key:
        hash_table.table[index] = None
        return True
    return False
```

平均时间复杂度：O(1)

## Python 中的哈希表

### 字典（Dictionary）

Python 的字典就是哈希表的实现：

```python
# 创建字典
my_dict = {}

# 插入键值对
my_dict['name'] = 'Alice'
my_dict['age'] = 25
my_dict['city'] = 'Beijing'

# 查找值
print(my_dict['name'])  # Alice
print(my_dict.get('age'))  # 25

# 删除键值对
del my_dict['city']

# 检查键是否存在
if 'name' in my_dict:
    print("name 存在")

# 获取所有键和值
print(my_dict.keys())   # dict_keys(['name', 'age'])
print(my_dict.values()) # dict_values(['Alice', 25])
print(my_dict.items())  # dict_items([('name', 'Alice'), ('age', 25)])
```

### 集合（Set）

集合是只存储键的哈希表：

```python
# 创建集合
my_set = set()

# 添加元素
my_set.add(1)
my_set.add(2)
my_set.add(3)

# 检查元素是否存在
if 2 in my_set:
    print("2 存在")

# 删除元素
my_set.remove(2)

# 集合操作
set1 = {1, 2, 3}
set2 = {3, 4, 5}

print(set1 | set2)  # 并集: {1, 2, 3, 4, 5}
print(set1 & set2)  # 交集: {3}
print(set1 - set2)  # 差集: {1, 2}
```

## 哈希表的应用

### 应用1：缓存系统

```python
class SimpleCache:
    def __init__(self, capacity=100):
        self.capacity = capacity
        self.cache = {}
    
    def get(self, key):
        """获取缓存值"""
        if key in self.cache:
            return self.cache[key]
        return None
    
    def put(self, key, value):
        """设置缓存值"""
        if len(self.cache) >= self.capacity:
            # 简单的缓存淘汰策略：删除第一个键
            first_key = next(iter(self.cache))
            del self.cache[first_key]
        
        self.cache[key] = value
    
    def clear(self):
        """清空缓存"""
        self.cache.clear()

# 使用示例
cache = SimpleCache(capacity=3)
cache.put('user1', 'Alice')
cache.put('user2', 'Bob')
cache.put('user3', 'Charlie')

print(cache.get('user1'))  # Alice
cache.put('user4', 'David')  # 淘汰 user1
print(cache.get('user1'))  # None
```

### 应用4：两数之和

```python
def two_sum(nums, target):
    """找出两数之和等于目标值的索引"""
    num_dict = {}
    
    for i, num in enumerate(nums):
        complement = target - num
        
        if complement in num_dict:
            return [num_dict[complement], i]
        
        num_dict[num] = i
    
    return []

# 使用示例
nums = [2, 7, 11, 15]
target = 9
print(two_sum(nums, target))  # [0, 1]
```

### 应用5：分组

```python
def group_anagrams(strs):
    """将字母异位词分组"""
    groups = {}
    
    for s in strs:
        # 排序字符串作为键
        key = ''.join(sorted(s))
        
        if key not in groups:
            groups[key] = []
        
        groups[key].append(s)
    
    return list(groups.values())

# 使用示例
words = ["eat", "tea", "tan", "ate", "nat", "bat"]
print(group_anagrams(words))
# [['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']]
```

## 哈希表的性能分析

### 时间复杂度

| 操作 | 平均情况 | 最坏情况 |
|------|----------|----------|
| 插入 | O(1) | O(n) |
| 查找 | O(1) | O(n) |
| 删除 | O(1) | O(n) |

### 影响性能的因素

1. **哈希函数质量**：好的哈希函数能减少冲突
2. **负载因子**：元素数量与哈希表大小的比值
3. **冲突解决策略**：不同的冲突解决方法性能不同
4. **数据分布**：数据的分布特征影响哈希效果

### 负载因子

```python
class LoadFactorHashTable:
    def __init__(self, initial_size=10, load_factor=0.75):
        self.size = initial_size
        self.load_factor = load_factor
        self.count = 0
        self.table = [[] for _ in range(self.size)]
    
    def _hash(self, key):
        return hash(key) % self.size
    
    def _resize(self):
        """调整哈希表大小"""
        old_table = self.table
        self.size *= 2
        self.table = [[] for _ in range(self.size)]
        self.count = 0
        
        for bucket in old_table:
            for key, value in bucket:
                self.put(key, value)
    
    def put(self, key, value):
        """插入键值对"""
        # 检查是否需要扩容
        if self.count / self.size >= self.load_factor:
            self._resize()
        
        index = self._hash(key)
        
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index][i] = (key, value)
                return
        
        self.table[index].append((key, value))
        self.count += 1
```

## 哈希表的优缺点

### 优点

1. **快速访问**：平均 O(1) 的查找、插入、删除
2. **灵活的键类型**：可以使用各种可哈希类型作为键
3. **动态大小**：可以根据需要动态调整大小
4. **简单易用**：API 简单直观

### 缺点

1. **无序性**：不保持元素的插入顺序
2. **冲突处理**：冲突处理可能影响性能
3. **空间开销**：需要额外的空间来避免冲突
4. **哈希函数依赖**：性能依赖于哈希函数的质量

## 哈希表 vs 其他数据结构

### 与数组对比

| 特性 | 哈希表 | 数组 |
|------|--------|------|
| 查找 | O(1) | O(n) |
| 插入 | O(1) | O(n) |
| 删除 | O(1) | O(n) |
| 有序性 | 无 | 有 |
| 内存 | 较高 | 较低 |

### 与树对比

| 特性 | 哈希表 | 平衡树 |
|------|--------|--------|
| 查找 | O(1) | O(log n) |
| 插入 | O(1) | O(log n) |
| 删除 | O(1) | O(log n) |
| 有序性 | 无 | 有 |
| 范围查询 | 不支持 | 支持 |

## 总结

哈希表是一种高效的键值对存储结构：

- **核心原理**：通过哈希函数将键映射到存储位置
- **快速操作**：平均 O(1) 的时间复杂度
- **冲突处理**：链地址法和开放寻址法
- **广泛应用**：缓存、计数、去重、查找等

哈希表在实际开发中应用广泛，是程序员必须掌握的重要数据结构之一。
