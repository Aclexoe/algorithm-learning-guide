# 栈与队列

## 栈

### 什么是栈

栈是一种**后进先出**（LIFO, Last In First Out）的线性数据结构。就像一摞盘子，你只能从最上面放盘子或取盘子。

### 栈的特性

1. **后进先出**：最后进入的元素最先被取出
2. **受限操作**：只能在栈顶进行插入和删除
3. **单端操作**：所有操作都在栈顶进行

### 栈的基本操作

#### 入栈（Push）

将元素压入栈顶。

```python
def push(stack, item):
    """入栈操作"""
    stack.append(item)
    return stack

# 使用示例
my_stack = []
push(my_stack, 10)
push(my_stack, 20)
push(my_stack, 30)
print(my_stack)  # [10, 20, 30]
```

时间复杂度：O(1)

#### 出栈（Pop）

从栈顶弹出元素。

```python
def pop(stack):
    """出栈操作"""
    if not stack:
        raise IndexError("栈为空")
    return stack.pop()

# 使用示例
my_stack = [10, 20, 30]
print(pop(my_stack))  # 30
print(pop(my_stack))  # 20
print(my_stack)       # [10]
```

时间复杂度：O(1)

#### 查看栈顶（Peek）

查看栈顶元素但不弹出。

```python
def peek(stack):
    """查看栈顶元素"""
    if not stack:
        raise IndexError("栈为空")
    return stack[-1]

# 使用示例
my_stack = [10, 20, 30]
print(peek(my_stack))  # 30
print(my_stack)        # [10, 20, 30]
```

时间复杂度：O(1)

#### 判断栈空（isEmpty）

检查栈是否为空。

```python
def is_empty(stack):
    """判断栈是否为空"""
    return len(stack) == 0

# 使用示例
my_stack = []
print(is_empty(my_stack))  # True
my_stack.append(10)
print(is_empty(my_stack))  # False
```

时间复杂度：O(1)

### 栈的实现

#### 使用列表实现

```python
class Stack:
    def __init__(self):
        self.items = []
    
    def push(self, item):
        """入栈"""
        self.items.append(item)
    
    def pop(self):
        """出栈"""
        if not self.is_empty():
            return self.items.pop()
        raise IndexError("栈为空")
    
    def peek(self):
        """查看栈顶"""
        if not self.is_empty():
            return self.items[-1]
        raise IndexError("栈为空")
    
    def is_empty(self):
        """判断栈空"""
        return len(self.items) == 0
    
    def size(self):
        """栈的大小"""
        return len(self.items)
    
    def display(self):
        """显示栈内容"""
        print("栈内容（从底到顶）：", self.items)
```

#### 使用链表实现

```python
class StackNode:
    def __init__(self, data):
        self.data = data
        self.next = None

class LinkedStack:
    def __init__(self):
        self.top = None
        self.size = 0
    
    def push(self, item):
        """入栈"""
        new_node = StackNode(item)
        new_node.next = self.top
        self.top = new_node
        self.size += 1
    
    def pop(self):
        """出栈"""
        if self.is_empty():
            raise IndexError("栈为空")
        
        data = self.top.data
        self.top = self.top.next
        self.size -= 1
        return data
    
    def peek(self):
        """查看栈顶"""
        if self.is_empty():
            raise IndexError("栈为空")
        return self.top.data
    
    def is_empty(self):
        """判断栈空"""
        return self.top is None
    
    def get_size(self):
        """栈的大小"""
        return self.size
```

### 栈的应用

#### 应用1：括号匹配

```python
def is_valid_parentheses(s):
    """检查括号是否匹配"""
    stack = []
    mapping = {')': '(', '}': '{', ']': '['}
    
    for char in s:
        if char in mapping.values():
            stack.append(char)
        elif char in mapping.keys():
            if not stack or stack.pop() != mapping[char]:
                return False
        else:
            continue
    
    return not stack

# 使用示例
print(is_valid_parentheses("()"))        # True
print(is_valid_parentheses("()[]{}"))    # True
print(is_valid_parentheses("(]"))        # False
print(is_valid_parentheses("([)]"))      # False
print(is_valid_parentheses("{[]}"))      # True
```

#### 应用2：表达式求值

```python
def evaluate_expression(expression):
    """计算后缀表达式"""
    stack = []
    tokens = expression.split()
    
    for token in tokens:
        if token.isdigit():
            stack.append(int(token))
        else:
            b = stack.pop()
            a = stack.pop()
            
            if token == '+':
                stack.append(a + b)
            elif token == '-':
                stack.append(a - b)
            elif token == '*':
                stack.append(a * b)
            elif token == '/':
                stack.append(a // b)
    
    return stack[0] if stack else 0

# 使用示例
print(evaluate_expression("3 4 + 2 *"))  # (3 + 4) * 2 = 14
print(evaluate_expression("5 1 2 + 4 * + 3 -"))  # 14
```

#### 应用3：函数调用栈

```python
def factorial(n):
    """递归计算阶乘"""
    if n <= 1:
        return 1
    return n * factorial(n - 1)

# 模拟函数调用栈
def factorial_iterative(n):
    """使用栈模拟递归"""
    stack = []
    result = 1
    
    # 将所有参数压入栈
    for i in range(n, 0, -1):
        stack.append(i)
    
    # 从栈中取出并计算
    while stack:
        result *= stack.pop()
    
    return result

print(factorial(5))          # 120
print(factorial_iterative(5))  # 120
```

#### 应用4：浏览器历史记录

```python
class BrowserHistory:
    def __init__(self):
        self.back_stack = []
        self.forward_stack = []
        self.current_page = None
    
    def visit(self, url):
        """访问新页面"""
        if self.current_page:
            self.back_stack.append(self.current_page)
        self.current_page = url
        self.forward_stack.clear()
        print(f"访问: {url}")
    
    def back(self):
        """后退"""
        if self.back_stack:
            self.forward_stack.append(self.current_page)
            self.current_page = self.back_stack.pop()
            print(f"后退到: {self.current_page}")
        else:
            print("没有更多历史记录")
        return self.current_page
    
    def forward(self):
        """前进"""
        if self.forward_stack:
            self.back_stack.append(self.current_page)
            self.current_page = self.forward_stack.pop()
            print(f"前进到: {self.current_page}")
        else:
            print("没有更多前进记录")
        return self.current_page

# 使用示例
browser = BrowserHistory()
browser.visit("google.com")
browser.visit("facebook.com")
browser.visit("twitter.com")
browser.back()      # 后退到 facebook.com
browser.back()      # 后退到 google.com
browser.forward()   # 前进到 facebook.com
```

## 队列

### 什么是队列

队列是一种**先进先出**（FIFO, First In First Out）的线性数据结构。就像排队买票，先来的人先买票。

### 队列的特性

1. **先进先出**：最先进入的元素最先被取出
2. **受限操作**：只能在队尾插入，队头删除
3. **双端操作**：插入和删除在不同端进行

### 队列的基本操作

#### 入队（Enqueue）

在队尾添加元素。

```python
def enqueue(queue, item):
    """入队操作"""
    queue.append(item)
    return queue

# 使用示例
my_queue = []
enqueue(my_queue, 10)
enqueue(my_queue, 20)
enqueue(my_queue, 30)
print(my_queue)  # [10, 20, 30]
```

时间复杂度：O(1)

#### 出队（Dequeue）

从队头移除元素。

```python
def dequeue(queue):
    """出队操作"""
    if not queue:
        raise IndexError("队列为空")
    return queue.pop(0)

# 使用示例
my_queue = [10, 20, 30]
print(dequeue(my_queue))  # 10
print(dequeue(my_queue))  # 20
print(my_queue)           # [30]
```

时间复杂度：O(n) - 使用列表实现时

#### 查看队首（Front）

查看队头元素但不移除。

```python
def front(queue):
    """查看队首元素"""
    if not queue:
        raise IndexError("队列为空")
    return queue[0]

# 使用示例
my_queue = [10, 20, 30]
print(front(my_queue))  # 10
print(my_queue)         # [10, 20, 30]
```

时间复杂度：O(1)

#### 判断队空（isEmpty）

检查队列是否为空。

```python
def is_empty(queue):
    """判断队列是否为空"""
    return len(queue) == 0

# 使用示例
my_queue = []
print(is_empty(my_queue))  # True
my_queue.append(10)
print(is_empty(my_queue))  # False
```

时间复杂度：O(1)

#### 使用链表实现

```python
class QueueNode:
    def __init__(self, data):
        self.data = data
        self.next = None

class LinkedQueue:
    def __init__(self):
        self.front = None
        self.rear = None
        self.size = 0
    
    def enqueue(self, item):
        """入队"""
        new_node = QueueNode(item)
        
        if self.is_empty():
            self.front = new_node
            self.rear = new_node
        else:
            self.rear.next = new_node
            self.rear = new_node
        
        self.size += 1
    
    def dequeue(self):
        """出队"""
        if self.is_empty():
            raise IndexError("队列为空")
        
        data = self.front.data
        self.front = self.front.next
        
        if self.front is None:
            self.rear = None
        
        self.size -= 1
        return data
    
    def get_front(self):
        """查看队首"""
        if self.is_empty():
            raise IndexError("队列为空")
        return self.front.data
    
    def is_empty(self):
        """判断队空"""
        return self.front is None
    
    def get_size(self):
        """队列大小"""
        return self.size
```

#### 使用collections.deque实现

```python
from collections import deque

class EfficientQueue:
    def __init__(self):
        self.items = deque()
    
    def enqueue(self, item):
        """入队 - O(1)"""
        self.items.append(item)
    
    def dequeue(self):
        """出队 - O(1)"""
        if not self.is_empty():
            return self.items.popleft()
        raise IndexError("队列为空")
    
    def front(self):
        """查看队首 - O(1)"""
        if not self.is_empty():
            return self.items[0]
        raise IndexError("队列为空")
    
    def is_empty(self):
        """判断队空"""
        return len(self.items) == 0
    
    def size(self):
        """队列大小"""
        return len(self.items)
```

### 队列的应用

#### 应用1：打印机任务队列

```python
import time
import random

class PrintQueue:
    def __init__(self):
        self.queue = EfficientQueue()
    
    def add_job(self, document):
        """添加打印任务"""
        self.queue.enqueue(document)
        print(f"添加打印任务: {document}")

        """处理打印任务"""
        if not self.queue.is_empty():

            print(f"正在打印: {document}")
            time.sleep(random.uniform(0.5, 1.5))  # 模拟打印时间
            print(f"打印完成: {document}")

        print(f"当前队列中有 {self.queue.size()} 个任务")
```

```python
class TaskScheduler:
    def __init__(self):
        self.task_queue = EfficientQueue()

        """添加任务"""
        task = {'name': task_name, 'priority': priority}
```

#### 应用3：广度优先搜索（BFS）

```python
from collections import deque

def bfs(graph, start):
    """广度优先搜索"""
    visited = set()
    queue = deque([start])
    result = []
    
    while queue:
        vertex = queue.popleft()
        if vertex not in visited:
            visited.add(vertex)
            result.append(vertex)
            
            # 添加未访问的邻居
            for neighbor in graph[vertex]:
                if neighbor not in visited:
                    queue.append(neighbor)
    
    return result

# 使用示例
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E']
}

print(bfs(graph, 'A'))  # ['A', 'B', 'C', 'D', 'E', 'F']
```

#### 应用4：滑动窗口最大值

```python
from collections import deque

def max_sliding_window(nums, k):
    """滑动窗口最大值"""
    if not nums or k <= 0:
        return []
    
    result = []
    deque_window = deque()  # 存储索引
    
    for i in range(len(nums)):
        # 移除超出窗口的元素
        while deque_window and deque_window[0] <= i - k:
            deque_window.popleft()
        
        # 移除比当前元素小的元素
        while deque_window and nums[deque_window[-1]] < nums[i]:
            deque_window.pop()
        
        deque_window.append(i)
        
        # 记录最大值
        if i >= k - 1:
            result.append(nums[deque_window[0]])
    
    return result

# 使用示例
print(max_sliding_window([1,3,-1,-3,5,3,6,7], 3))  # [3,3,5,5,6,7]
```

## 双端队列

### 什么是双端队列

双端队列（Deque, Double-Ended Queue）允许在两端进行插入和删除操作。

### 双端队列的实现

```python
from collections import deque

class Deque:
    def __init__(self):
        self.items = deque()
    
    def add_front(self, item):
        """在前端添加"""
        self.items.appendleft(item)
    
    def add_rear(self, item):
        """在后端添加"""
        self.items.append(item)
    
    def remove_front(self):
        """从前端移除"""
        if not self.is_empty():
            return self.items.popleft()
        raise IndexError("双端队列为空")
    
    def remove_rear(self):
        """从后端移除"""
        if not self.is_empty():
            return self.items.pop()
        raise IndexError("双端队列为空")
    
    def is_empty(self):
        """判断是否为空"""
        return len(self.items) == 0
    
    def size(self):
        """返回大小"""
        return len(self.items)
```

### 双端队列的应用

#### 应用：回文检查

```python
def is_palindrome(s):
    """检查是否为回文"""
    deque_str = Deque()
    
    for char in s:
        deque_str.add_rear(char)
    
    while deque_str.size() > 1:
        front = deque_str.remove_front()
        rear = deque_str.remove_rear()
        
        if front != rear:
            return False
    
    return True

# 使用示例
print(is_palindrome("racecar"))  # True
print(is_palindrome("hello"))    # False
print(is_palindrome("a"))        # True
```

## 栈 vs 队列

### 对比总结

| 特性 | 栈 | 队列 |
|------|------|------|
| 原则 | 后进先出 (LIFO) | 先进先出 (FIFO) |
| 插入端 | 栈顶 | 队尾 |
| 删除端 | 栈顶 | 队头 |
| 主要操作 | push, pop | enqueue, dequeue |
| 典型应用 | 函数调用、括号匹配 | 任务调度、BFS |

### 选择建议

#### 选择栈的情况

1. 需要后进先出的顺序
2. 需要回溯功能
3. 函数调用和递归
4. 表达式求值

#### 选择队列的情况

1. 需要先进先出的顺序
2. 任务调度
3. 广度优先搜索
4. 缓冲区管理

## 总结

栈和队列是重要的受限线性数据结构：

- **栈**：后进先出，适合需要回溯的场景
- **队列**：先进先出，适合需要按顺序处理的场景
- **实现方式**：可以用数组或链表实现
- **广泛应用**：在系统设计和算法中有重要应用
