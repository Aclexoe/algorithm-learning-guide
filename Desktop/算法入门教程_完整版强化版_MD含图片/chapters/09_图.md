# 图

## 什么是图

图是一种非线性数据结构，由顶点（Vertex）和边（Edge）组成,用于表示对象之间的关系。图广泛应用于社交网络、地图导航、网络拓扑等领域。

### 图的基本概念

- **顶点（Vertex）**：图中的节点
- **边（Edge）**：连接顶点的线
- **度（Degree）**：与顶点相连的边的数量
- **路径（Path）**：顶点之间的连接序列
- **环（Cycle）**：起点和终点相同的路径
- **连通图**：任意两个顶点之间都有路径
- **权重（Weight）**：边上的数值，表示距离、成本等

### 图的分类

#### 按边的方向分类

1. **无向图**：边没有方向
2. **有向图**：边有方向

#### 按边的权重分类

1. **无权图**：边没有权重
2. **有权图**：边有权重

#### 按边的数量分类

1. **稀疏图**：边的数量远小于顶点数量的平方
2. **稠密图**：边的数量接近顶点数量的平方

## 图的表示方法

### 邻接矩阵

使用二维矩阵表示图，矩阵中的元素表示顶点之间是否有边。

```python
class GraphMatrix:
    def __init__(self, num_vertices, directed=False):
        self.num_vertices = num_vertices
        self.directed = directed
        self.matrix = [[0] * num_vertices for _ in range(num_vertices)]
    
    def add_edge(self, u, v, weight=1):
        """添加边"""
        if 0 <= u < self.num_vertices and 0 <= v < self.num_vertices:
            self.matrix[u][v] = weight
            if not self.directed:
                self.matrix[v][u] = weight
    
    def remove_edge(self, u, v):
        """删除边"""
        if 0 <= u < self.num_vertices and 0 <= v < self.num_vertices:
            self.matrix[u][v] = 0
            if not self.directed:
                self.matrix[v][u] = 0
    
    def has_edge(self, u, v):
        """检查边是否存在"""
        if 0 <= u < self.num_vertices and 0 <= v < self.num_vertices:
            return self.matrix[u][v] != 0
        return False
    
    def get_neighbors(self, v):
        """获取顶点的邻居"""
        if 0 <= v < self.num_vertices:
            neighbors = []
            for i in range(self.num_vertices):
                if self.matrix[v][i] != 0:
                    neighbors.append(i)
            return neighbors
        return []
    
    def display(self):
        """显示邻接矩阵"""
        for row in self.matrix:
            print(row)

# 使用示例
graph = GraphMatrix(4)
graph.add_edge(0, 1)
graph.add_edge(0, 2)
graph.add_edge(1, 2)
graph.add_edge(2, 3)
graph.display()
```

### 邻接表

使用字典或列表表示图，每个顶点存储其相邻的顶点。

```python
class GraphAdjList:
    def __init__(self, directed=False):
        self.graph = {}
        self.directed = directed
    
    def add_vertex(self, vertex):
        """添加顶点"""
        if vertex not in self.graph:
            self.graph[vertex] = []
    
    def add_edge(self, u, v, weight=1):
        """添加边"""
        if u not in self.graph:
            self.add_vertex(u)
        if v not in self.graph:
            self.add_vertex(v)
        
        self.graph[u].append((v, weight))
        if not self.directed:
            self.graph[v].append((u, weight))
    
    def remove_edge(self, u, v):
        """删除边"""
        if u in self.graph and v in self.graph:
            self.graph[u] = [(neighbor, weight) for neighbor, weight in self.graph[u] if neighbor != v]
            if not self.directed:
                self.graph[v] = [(neighbor, weight) for neighbor, weight in self.graph[v] if neighbor != u]
    
    def has_edge(self, u, v):
        """检查边是否存在"""
        if u in self.graph:
            for neighbor, _ in self.graph[u]:
                if neighbor == v:
                    return True
        return False
    
    def get_neighbors(self, v):
        """获取顶点的邻居"""
        if v in self.graph:
            return [neighbor for neighbor, _ in self.graph[v]]
        return []
    
    def display(self):
        """显示邻接表"""
        for vertex in self.graph:
            print(f"{vertex}: {self.graph[vertex]}")

# 使用示例
graph = GraphAdjList()
graph.add_edge(0, 1)
graph.add_edge(0, 2)
graph.add_edge(1, 2)
graph.add_edge(2, 3)
graph.display()
```

## 图的遍历

### 深度优先搜索（DFS）

从起始顶点开始，沿着一条路径尽可能深入，无法继续时回溯。

```python
def dfs(graph, start, visited=None):
    """深度优先搜索"""
    if visited is None:
        visited = set()
    
    visited.add(start)
    print(start, end=" ")
    
    for neighbor in graph.get_neighbors(start):
        if neighbor not in visited:
            dfs(graph, neighbor, visited)
    
    return visited

# 迭代版本
def dfs_iterative(graph, start):
    """深度优先搜索迭代版本"""
    visited = set()
    stack = [start]
    
    while stack:
        vertex = stack.pop()
        if vertex not in visited:
            visited.add(vertex)
            print(vertex, end=" ")
            
            # 将邻居按相反顺序压入栈，保证顺序正确
            for neighbor in reversed(graph.get_neighbors(vertex)):
                if neighbor not in visited:
                    stack.append(neighbor)
    
    return visited
```

### 广度优先搜索（BFS）

从起始顶点开始，先访问所有相邻顶点，再访问相邻顶点的相邻顶点。

```python
from collections import deque

def bfs(graph, start):
    """广度优先搜索"""
    visited = set()
    queue = deque([start])
    visited.add(start)
    
    while queue:
        vertex = queue.popleft()
        print(vertex, end=" ")
        
        for neighbor in graph.get_neighbors(vertex):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    
    return visited
```

## 最短路径算法

### Dijkstra算法

用于计算图中从一个顶点到其他所有顶点的最短路径（适用于非负权重图）。

```python
import heapq

def dijkstra(graph, start):
    """Dijkstra最短路径算法"""
    distances = {vertex: float('infinity') for vertex in graph.graph}
    distances[start] = 0
    
    priority_queue = [(0, start)]
    visited = set()
    
    while priority_queue:
        current_distance, current_vertex = heapq.heappop(priority_queue)
        
        if current_vertex in visited:
            continue
        
        visited.add(current_vertex)
        
        for neighbor, weight in graph.graph[current_vertex]:
            distance = current_distance + weight
            
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))
    
    return distances

# 使用示例
graph = GraphAdjList()
graph.add_edge(0, 1, 4)
graph.add_edge(0, 2, 2)
graph.add_edge(1, 2, 1)
graph.add_edge(1, 3, 5)
graph.add_edge(2, 3, 8)
graph.add_edge(2, 4, 10)
graph.add_edge(3, 4, 2)

distances = dijkstra(graph, 0)
print(distances)  # {0: 0, 1: 3, 2: 2, 3: 8, 4: 10}
```

### Floyd-Warshall算法

计算图中所有顶点对之间的最短路径。

```python
def floyd_warshall(graph):
    """Floyd-Warshall算法"""
    vertices = list(graph.graph.keys())
    n = len(vertices)
    
    # 初始化距离矩阵
    dist = [[float('infinity')] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    
    # 填充初始距离
    for i in range(n):
        for j, weight in graph.graph[vertices[i]]:
            dist[i][j] = weight
    
    # 计算最短路径
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    
    return dist
```

## 最小生成树

### Prim算法

从一个顶点开始，逐步添加边，直到生成最小生成树。

```python
def prim(graph, start):
    """Prim最小生成树算法"""
    mst = []
    visited = set([start])
    edges = []
    
    # 添加起始顶点的所有边
    for neighbor, weight in graph.graph[start]:
        heapq.heappush(edges, (weight, start, neighbor))
    
    while edges and len(visited) < len(graph.graph):
        weight, u, v = heapq.heappop(edges)
        
        if v not in visited:
            visited.add(v)
            mst.append((u, v, weight))
            
            # 添加新顶点的所有边
            for neighbor, w in graph.graph[v]:
                if neighbor not in visited:
                    heapq.heappush(edges, (w, v, neighbor))
    
    return mst
```

### Kruskal算法

按权重从小到大选择边，避免形成环，直到生成最小生成树。

```python
class UnionFind:
    def __init__(self, vertices):
        self.parent = {v: v for v in vertices}
        self.rank = {v: 0 for v in vertices}
    
    def find(self, item):
        """查找根节点"""
        while self.parent[item] != item:
            item = self.parent[item]
        return item
    
    def union(self, set1, set2):
        """合并两个集合"""
        root1 = self.find(set1)
        root2 = self.find(set2)
        
        if root1 != root2:
            if self.rank[root1] > self.rank[root2]:
                self.parent[root2] = root1
            else:
                self.parent[root1] = root2
                if self.rank[root1] == self.rank[root2]:
                    self.rank[root2] += 1

def kruskal(graph):
    """Kruskal最小生成树算法"""
    edges = []
    for u in graph.graph:
        for v, weight in graph.graph[u]:
            edges.append((weight, u, v))
    
    edges.sort()  # 按权重排序
    vertices = list(graph.graph.keys())
    uf = UnionFind(vertices)
    mst = []
    
    for weight, u, v in edges:
        if uf.find(u) != uf.find(v):
            uf.union(u, v)
            mst.append((u, v, weight))
    
    return mst
```

## 拓扑排序

对有向无环图（DAG）进行排序，使得对于每一条边 u→v，u 都在 v 之前。

```python
def topological_sort(graph):
    """拓扑排序"""
    in_degree = {v: 0 for v in graph.graph}
    
    # 计算入度
    for u in graph.graph:
        for v, _ in graph.graph[u]:
            in_degree[v] += 1
    
    # 找到入度为0的顶点
    queue = deque([v for v in in_degree if in_degree[v] == 0])
    result = []
    
    while queue:
        vertex = queue.popleft()
        result.append(vertex)
        
        for neighbor, _ in graph.graph[vertex]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)
    
    if len(result) != len(graph.graph):
        return None  # 图中有环
    
    return result
```

## 图的应用

### 应用1：社交网络分析

```python
class SocialNetwork:
    def __init__(self):
        self.graph = GraphAdjList(directed=True)
    
    def add_friendship(self, user1, user2):
        """添加好友关系"""
        self.graph.add_edge(user1, user2)
    
    def get_friends(self, user):
        """获取好友列表"""
        return self.graph.get_neighbors(user)
    
    def find_mutual_friends(self, user1, user2):
        """查找共同好友"""
        friends1 = set(self.get_friends(user1))
        friends2 = set(self.get_friends(user2))
        return friends1 & friends2
    
    def suggest_friends(self, user):
        """推荐好友（好友的好友）"""
        friends = self.get_friends(user)
        suggestions = {}
        
        for friend in friends:
            for friend_of_friend in self.get_friends(friend):
                if friend_of_friend != user and friend_of_friend not in friends:
                    suggestions[friend_of_friend] = suggestions.get(friend_of_friend, 0) + 1
        
        # 按共同好友数量排序
        return sorted(suggestions.items(), key=lambda x: x[1], reverse=True)
```

### 应用2：地图导航

```python
class MapNavigation:
    def __init__(self):
        self.graph = GraphAdjList(directed=False)
    
    def add_location(self, location):
        """添加地点"""
        self.graph.add_vertex(location)
    
    def add_road(self, location1, location2, distance):
        """添加道路"""
        self.graph.add_edge(location1, location2, distance)
    
    def find_shortest_path(self, start, end):
        """查找最短路径"""
        distances = dijkstra(self.graph, start)
        return distances.get(end, float('infinity'))
    
    def find_all_paths(self, start, end, path=None):
        """查找所有路径"""
        if path is None:
            path = []
        
        path = path + [start]
        
        if start == end:
            return [path]
        
        if start not in self.graph.graph:
            return []
        
        paths = []
        for neighbor in self.graph.get_neighbors(start):
            if neighbor not in path:
                new_paths = self.find_all_paths(neighbor, end, path)
                paths.extend(new_paths)
        
        return paths
```

class CourseScheduler:

### 应用4：网络连通性检测

```python
def is_connected(graph):
    """检测图是否连通"""
    if not graph.graph:
        return True
    
    start = next(iter(graph.graph))
    visited = dfs(graph, start)
    
    return len(visited) == len(graph.graph)

def find_connected_components(graph):
    """查找连通分量"""
    visited = set()
    components = []
    
    for vertex in graph.graph:
        if vertex not in visited:
            component = dfs(graph, vertex, visited)
            components.append(component)
    
    return components
```

## 图的复杂度分析

| 操作 | 邻接矩阵 | 邻接表 |
|------|----------|--------|
| 添加顶点 | O(V²) | O(1) |
| 添加边 | O(1) | O(1) |
| 删除边 | O(1) | O(E) |
| 检查边 | O(1) | O(degree) |
| 遍历邻居 | O(V) | O(degree) |
| 空间复杂度 | O(V²) | O(V+E) |

其中 V 是顶点数，E 是边数，degree 是顶点的度。

## 图的优缺点

### 优点

1. **表达能力强**：可以表示复杂的关系
2. **应用广泛**：在许多领域都有应用
3. **算法丰富**：有许多成熟的图算法
4. **灵活性好**：可以表示各种类型的关系

### 缺点

1. **空间复杂度高**：特别是邻接矩阵表示
2. **算法复杂**：许多图算法时间复杂度较高
3. **实现复杂**：相比线性数据结构更复杂
4. **性能依赖**：性能严重依赖于图的表示方式

## 总结

图是一种强大的非线性数据结构：

- **基本组成**：顶点和边，表示对象之间的关系
- **表示方法**：邻接矩阵和邻接表
- **遍历算法**：深度优先搜索和广度优先搜索
- **重要算法**：最短路径、最小生成树、拓扑排序
- **广泛应用**：社交网络、地图导航、课程安排等

图在计算机科学中有重要地位，掌握图的基本概念和算法对解决复杂问题至关重要。
