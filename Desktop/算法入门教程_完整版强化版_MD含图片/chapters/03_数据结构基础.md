# 数据结构基础

## 什么是数据结构

数据结构是计算机存储、组织数据的方式。数据结构旨在通过特定的结构来提高数据的访问和操作效率。

### 数据结构的重要性

1. **提高效率**：合适的数据结构可以显著提高算法效率
2. **节省内存**：优化数据存储，减少内存占用
3. **简化操作**：使数据操作更加直观和便捷
4. **解决问题**：不同问题需要不同的数据结构

### 数据结构与算法的关系

数据结构和算法是相辅相成的：
- **数据结构**是算法的基础
- **算法**依赖数据结构来实现
- 好的算法需要合适的数据结构支撑

## 数据结构的分类

### 按逻辑结构分类

#### 1. 线性结构

数据元素之间存在一对一的关系：

- **数组**：连续内存存储，随机访问快
- **链表**：非连续存储，插入删除快
- **栈**：后进先出（LIFO）
- **队列**：先进先出（FIFO）

#### 2. 非线性结构

数据元素之间存在一对多或多对多的关系：

- **树**：层次结构，一对多关系
- **图**：网络结构，多对多关系
- **堆**：特殊的树结构

### 按物理结构分类

#### 1. 顺序存储

使用连续的内存空间存储数据：
- 优点：随机访问快，空间利用率高
- 缺点：插入删除慢，需要预先分配内存

#### 2. 链式存储

使用指针连接分散的内存块：
- 优点：插入删除快，内存动态分配
- 缺点：随机访问慢，需要额外指针空间

## 基本数据类型 vs 数据结构

### 基本数据类型

编程语言提供的基础类型：
- 整数（int）
- 浮点数（float）
- 字符串（string）
- 布尔值（boolean）

## 数据结构的选择

### 选择考虑因素

1. **操作需求**
   - 频繁查找：选择哈希表或平衡树
   - 频繁插入删除：选择链表
   - 需要排序：选择数组或树

2. **时间复杂度**
   - 查找效率
   - 插入删除效率
   - 遍历效率

3. **空间复杂度**
   - 内存占用
   - 空间利用率

4. **实现复杂度**
   - 开发时间
   - 维护成本

## 数据结构的操作

### 常见操作

1. **访问**：读取或修改数据
2. **插入**：添加新数据
3. **删除**：移除数据
4. **查找**：搜索特定数据
5. **遍历**：访问所有数据
6. **排序**：按特定顺序排列

### 操作复杂度对比

| 数据结构 | 访问 | 插入 | 删除 | 查找 |
|----------|------|------|------|------|
| 数组 | O(1) | O(n) | O(n) | O(n) |
| 链表 | O(n) | O(1) | O(1) | O(n) |
| 栈 | O(n) | O(1) | O(1) | O(n) |
| 队列 | O(n) | O(1) | O(1) | O(n) |
| 哈希表 | - | O(1) | O(1) | O(1) |
| 二叉搜索树 | O(log n) | O(log n) | O(log n) | O(log n) |

## 数据结构的应用实例

### 应用1：浏览器历史记录（栈）

```python
class BrowserHistory:
    def __init__(self):
        self.back_stack = []
        self.forward_stack = []
        self.current_page = None
    
    def visit(self, url):
        if self.current_page:
            self.back_stack.append(self.current_page)
        self.current_page = url
        self.forward_stack.clear()
    
    def back(self):
        if self.back_stack:
            self.forward_stack.append(self.current_page)
            self.current_page = self.back_stack.pop()
        return self.current_page
    
    def forward(self):
        if self.forward_stack:
            self.back_stack.append(self.current_page)
            self.current_page = self.forward_stack.pop()
        return self.current_page
```

### 应用2：打印队列（队列）

```python
from queue import Queue

class PrintQueue:
    def __init__(self):
        self.queue = Queue()
    
    def add_job(self, document):
        self.queue.put(document)
        print(f"添加打印任务: {document}")
    
    def process_job(self):
        if not self.queue.empty():
            document = self.queue.get()
            print(f"正在打印: {document}")
            return document
        print("打印队列为空")
        return None
```

### 应用3：联系人管理（哈希表）

```python
class ContactManager:
    def __init__(self):
        self.contacts = {}
    
    def add_contact(self, name, phone):
        self.contacts[name] = phone
        print(f"添加联系人: {name} - {phone}")
    
    def get_contact(self, name):
        return self.contacts.get(name, "联系人不存在")
    
    def delete_contact(self, name):
        if name in self.contacts:
            del self.contacts[name]
            print(f"删除联系人: {name}")
        else:
            print("联系人不存在")
```

## 数据结构的设计原则

### 1. 封装性

将数据和操作封装在一起，隐藏实现细节。

```python
class Stack:
    def __init__(self):
        self._items = []  # 使用下划线表示私有
    
    def push(self, item):
        self._items.append(item)
    
    def pop(self):
        if not self.is_empty():
            return self._items.pop()
        raise IndexError("栈为空")
    
    def is_empty(self):
        return len(self._items) == 0
```

### 2. 一致性

保持接口的一致性，便于使用和理解。

### 3. 效率性

选择合适的底层实现，优化操作效率。

### 4. 可扩展性

设计时考虑未来的扩展需求。
