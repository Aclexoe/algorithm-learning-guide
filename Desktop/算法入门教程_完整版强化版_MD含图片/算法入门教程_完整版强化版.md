## 什么是算法

算法是解决特定问题的一系列明确步骤。就像菜谱告诉你如何做一道菜一样，算法告诉计算机如何解决一个计算问题。

### 算法的特征

一个好的算法应该具备以下特征：

1. **有穷性**：算法在有限步骤内结束
2. **确定性**：每一步都有明确的定义，没有歧义
3. **输入**：算法有零个或多个输入
4. **输出**：算法产生一个或多个输出
5. **有效性**：每一步都能在有限时间内完成

### 算法的例子

让我们看一个简单的例子：计算 1 到 n 的和。

```python
def sum_to_n(n):
    """计算 1 到 n 的和"""
    total = 0
    for i in range(1, n + 1):
        total += i
    return total

# 使用示例
result = sum_to_n(100)
print(f"1 到 100 的和是：{result}")
```

这个算法清晰地定义了计算步骤，对于任何正整数 n 都能得到正确结果。

# 第2章 复杂度分析

> **本章图解**：常见时间复杂度增长趋势图

![常见时间复杂度增长趋势图](figures/02_complexity_growth.svg)


## 为什么需要复杂度分析

在编写算法时，我们需要评估算法的效率。复杂度分析就是一种评估算法性能的方法，它帮助我们：

1. **预测算法性能**：在运行前预估算法的执行效率
2. **比较算法优劣**：选择最适合问题的算法
3. **优化代码**：找出性能瓶颈并改进

复杂度分析主要从两个维度评估算法：
- **时间复杂度**：算法执行时间随输入规模增长的变化趋势
- **空间复杂度**：算法所需存储空间随输入规模增长的变化趋势

## 时间复杂度

### 基本概念

时间复杂度表示算法执行时间与输入规模 n 之间的关系。我们通常使用大 O 表示法来描述时间复杂度。

大 O 表示法关注的是算法的**增长趋势**，而不是具体的执行时间。它忽略了常数项和低阶项，只保留最高阶项。

### 常见时间复杂度

| 复杂度 | 表示 | 特点 | 示例 |
|--------|------|------|------|
| O(1) | 常数时间 | 执行时间不随输入规模变化 | 数组索引访问 |
| O(log n) | 对数时间 | 执行时间随输入规模对数增长 | 二分查找 |
| O(n) | 线性时间 | 执行时间与输入规模成正比 | 线性查找 |
| O(n log n) | 线性对数时间 | 常见于高效排序算法 | 归并排序 |
| O(n²) | 平方时间 | 执行时间与输入规模平方成正比 | 冒泡排序 |
| O(2ⁿ) | 指数时间 | 执行时间随输入规模指数增长 | 递归斐波那契 |
| O(n!) | 阶乘时间 | 执行时间极快增长 | 全排列 |

### 时间复杂度分析示例

#### O(1) - 常数时间

```python
def get_first_element(arr):
    """获取数组第一个元素"""
    if len(arr) > 0:
        return arr[0]
    return None
```

无论数组多大，这个操作都只需要一步，时间复杂度为 O(1)。

#### O(n) - 线性时间

```python
def find_max(arr):
    """查找数组中的最大值"""
    if not arr:
        return None
    
    max_val = arr[0]
    for val in arr:
        if val > max_val:
            max_val = val
    return max_val
```

需要遍历整个数组，时间复杂度为 O(n)。

#### O(n²) - 平方时间

```python
def bubble_sort(arr):
    """冒泡排序"""
    n = len(arr)
    for i in range(n):
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr
```

嵌套循环，外层执行 n 次，内层平均执行 n/2 次，时间复杂度为 O(n²)。

#### O(log n) - 对数时间

```python
def binary_search(arr, target):
    """二分查找"""
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return -1
```

每次查找都将搜索范围减半，时间复杂度为 O(log n)。

### 复杂度计算规则

1. **加法法则**：如果算法由多个顺序执行的步骤组成，总复杂度取最大的那个
   ```python
   def example(n):
       # O(n)
       for i in range(n):
           print(i)
       # O(n²)
       for i in range(n):
           for j in range(n):
               print(i, j)
       # 总复杂度：O(n) + O(n²) = O(n²)
   ```

2. **乘法法则**：如果算法包含嵌套循环，复杂度相乘
   ```python
   def example(n):
       for i in range(n):          # O(n)
           for j in range(n):      # O(n)
               print(i, j)         # O(1)
       # 总复杂度：O(n) × O(n) = O(n²)
   ```

3. **忽略常数**：O(2n) = O(n)，O(3n²) = O(n²)

4. **忽略低阶项**：O(n² + n) = O(n²)，O(n³ + n² + n) = O(n³)

## 空间复杂度

### 基本概念

空间复杂度表示算法执行过程中所需存储空间与输入规模 n 之间的关系。

### 常见空间复杂度

| 复杂度 | 表示 | 特点 | 示例 |
|--------|------|------|------|
| O(1) | 常数空间 | 只使用固定数量的额外空间 | 变量交换 |
| O(n) | 线性空间 | 额外空间与输入规模成正比 | 数组复制 |
| O(n²) | 平方空间 | 额外空间与输入规模平方成正比 | 二维数组 |
| O(log n) | 对数空间 | 递归调用栈的空间 | 二分查找递归 |

### 空间复杂度分析示例

#### O(1) - 常数空间

```python
def swap(a, b):
    """交换两个变量的值"""
    temp = a
    a = b
    b = temp
    return a, b
```

只使用了固定数量的变量，空间复杂度为 O(1)。

#### O(n) - 线性空间

```python
def reverse_array(arr):
    """反转数组"""
    n = len(arr)
    reversed_arr = [0] * n  # 需要额外的 n 个空间
    for i in range(n):
        reversed_arr[i] = arr[n - 1 - i]
    return reversed_arr
```

创建了一个与原数组大小相同的新数组，空间复杂度为 O(n)。

#### O(n) - 递归空间

```python
def factorial(n):
    """递归计算阶乘"""
    if n <= 1:
        return 1
    return n * factorial(n - 1)
```

递归深度为 n，每次调用都需要栈空间，空间复杂度为 O(n)。

## 时间与空间的权衡

在实际应用中，我们经常需要在时间和空间之间进行权衡：

### 以空间换时间

```python
# 方法1：时间复杂度 O(n)，空间复杂度 O(1)
def fibonacci_1(n):
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b

# 方法2：时间复杂度 O(1)，空间复杂度 O(n)
def fibonacci_2(n):
    if n <= 1:
        return n
    fib = [0] * (n + 1)
    fib[1] = 1
    for i in range(2, n + 1):
        fib[i] = fib[i - 1] + fib[i - 2]
    return fib[n]
```

方法1节省空间但需要计算，方法2预先计算存储但占用更多空间。

### 以时间换空间

在内存受限的情况下，我们可以选择牺牲时间来节省空间。

## 复杂度分析的实际应用

### 1. 选择合适的算法

```python
# 小数据量：简单排序
def sort_small_array(arr):
    if len(arr) < 100:
        return bubble_sort(arr)  # O(n²)
    else:
        return merge_sort(arr)   # O(n log n)
```

### 2. 优化代码性能

```python
# 优化前：O(n²)
def find_duplicates_slow(arr):
    duplicates = []
    for i in range(len(arr)):
        for j in range(i + 1, len(arr)):
            if arr[i] == arr[j] and arr[i] not in duplicates:
                duplicates.append(arr[i])
    return duplicates

# 优化后：O(n)
def find_duplicates_fast(arr):
    seen = set()
    duplicates = set()
    for item in arr:
        if item in seen:
            duplicates.add(item)
        else:
            seen.add(item)
    return list(duplicates)
```

### 3. 预估系统性能

通过复杂度分析，我们可以预估系统在不同数据规模下的表现。

## 常见误区

1. **忽略最坏情况**：应该考虑最坏情况下的复杂度
2. **过度优化**：不是所有地方都需要最优复杂度
3. **只关注时间**：空间复杂度同样重要
4. **过早优化**：先确保正确性，再考虑性能

## 什么是数据结构

数据结构是计算机存储、组织数据的方式。数据结构旨在通过特定的结构来提高数据的访问和操作效率。

### 数据结构的重要性

1. **提高效率**：合适的数据结构可以显著提高算法效率
2. **节省内存**：优化数据存储，减少内存占用
3. **简化操作**：使数据操作更加直观和便捷
4. **解决问题**：不同问题需要不同的数据结构

### 数据结构与算法的关系

数据结构和算法是相辅相成的：
- **数据结构**是算法的基础
- **算法**依赖数据结构来实现
- 好的算法需要合适的数据结构支撑

## 数据结构的分类

### 按逻辑结构分类

#### 1. 线性结构

数据元素之间存在一对一的关系：

- **数组**：连续内存存储，随机访问快
- **链表**：非连续存储，插入删除快
- **栈**：后进先出（LIFO）
- **队列**：先进先出（FIFO）

#### 2. 非线性结构

数据元素之间存在一对多或多对多的关系：

- **树**：层次结构，一对多关系
- **图**：网络结构，多对多关系
- **堆**：特殊的树结构

### 按物理结构分类

#### 1. 顺序存储

使用连续的内存空间存储数据：
- 优点：随机访问快，空间利用率高
- 缺点：插入删除慢，需要预先分配内存

#### 2. 链式存储

使用指针连接分散的内存块：
- 优点：插入删除快，内存动态分配
- 缺点：随机访问慢，需要额外指针空间

## 抽象数据类型（ADT）

抽象数据类型定义了数据的操作和行为，而不涉及具体实现。

### ADT 的组成

1. **数据对象**：数据的集合
2. **数据关系**：数据之间的关系
3. **基本操作**：对数据的操作

### 示例：栈的 ADT

## 基本数据类型 vs 数据结构

### 基本数据类型

编程语言提供的基础类型：
- 整数（int）
- 浮点数（float）
- 字符串（string）
- 布尔值（boolean）

### 数据结构

基于基本类型构建的复合结构：
- 数组、链表、栈、队列
- 树、图、哈希表
- 由基本类型组合而成

## 数据结构的选择

### 选择考虑因素

1. **操作需求**
   - 频繁查找：选择哈希表或平衡树
   - 频繁插入删除：选择链表
   - 需要排序：选择数组或树

2. **时间复杂度**
   - 查找效率
   - 插入删除效率
   - 遍历效率

3. **空间复杂度**
   - 内存占用
   - 空间利用率

4. **实现复杂度**
   - 开发时间
   - 维护成本

### 选择示例

#### 场景1：需要快速查找


#### 场景2：需要频繁插入删除

```python
# 使用链表
```

## 数组

### 什么是数组

数组是最基本的数据结构，它是一组相同类型数据的集合，存储在连续的内存空间中。

### 数组的特性

1. **连续内存**：元素在内存中连续存储
2. **固定大小**：创建时需要指定大小（静态数组）
3. **随机访问**：可以通过索引快速访问任意元素
4. **相同类型**：所有元素必须是相同类型

## 链表

### 什么是链表

链表是一种线性数据结构，通过指针将一组分散的内存块连接起来。每个节点包含数据和指向下一个节点的指针。

### 链表的特性

1. **非连续内存**：节点可以分散在内存中
2. **动态大小**：可以动态添加或删除节点
3. **顺序访问**：必须从头节点开始遍历
4. **指针连接**：通过指针连接各个节点

### 链表的类型

#### 单向链表

每个节点只包含指向下一个节点的指针。

```python
class ListNode:
    def __init__(self, data=0):
        self.data = data
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None
    
    def append(self, data):
        """在链表末尾添加节点"""
        new_node = ListNode(data)
        if not self.head:
            self.head = new_node
            return
        
        current = self.head
        while current.next:
            current = current.next
        current.next = new_node
    
    def display(self):
        """显示链表内容"""
        current = self.head
        while current:
            print(current.data, end=" -> ")
            current = current.next
        print("None")
    
    def find(self, data):
        """查找节点"""
        current = self.head
        while current:
            if current.data == data:
                return current
            current = current.next
        return None
    
    def delete(self, data):
        """删除节点"""
        if not self.head:
            return
        
        if self.head.data == data:
            self.head = self.head.next
            return
        
        current = self.head
        while current.next:
            if current.next.data == data:
                current.next = current.next.next
                return
            current = current.next
```

#### 双向链表

每个节点包含指向前驱节点和后继节点的指针。

```python
            print(current.data, end=" -> ")
```

### 链表的基本操作

#### 访问元素

```python
def access_node(head, index):
    """访问指定位置的节点"""
    current = head
    count = 0
    
    while current:
        if count == index:
            return current.data
        current = current.next
        count += 1
    
    raise IndexError("索引越界")
```

时间复杂度：O(n)

#### 插入节点

```python
def insert_node(head, index, data):
    """在指定位置插入节点"""
    new_node = ListNode(data)
    
    if index == 0:
        new_node.next = head
        return new_node
    
    current = head
    count = 0
    
    while current and count < index - 1:
        current = current.next
        count += 1
    
    if not current:
        raise IndexError("索引越界")
    
    new_node.next = current.next
    current.next = new_node
    
    return head
```

时间复杂度：O(n)

#### 删除节点

```python
def delete_node(head, data):
    """删除指定数据的节点"""
    if not head:
        return None
    
    if head.data == data:
        return head.next
    
    current = head
    while current.next:
        if current.next.data == data:
            current.next = current.next.next
            return head
        current = current.next
    
    return head
```

时间复杂度：O(n)

### 链表的优缺点

#### 优点

1. **动态大小**：可以动态添加或删除节点
2. **插入删除快**：已知位置时插入删除为 O(1)
3. **内存灵活**：不需要连续内存空间

#### 缺点

1. **访问慢**：随机访问需要 O(n) 时间
2. **额外空间**：每个节点需要额外的指针空间
3. **缓存不友好**：非连续存储，缓存命中率低

### 链表的应用场景

1. **频繁插入删除**：如文本编辑器
2. **动态数据集合**：如内存管理
3. **实现其他数据结构**：如栈、队列、图

```python
        self.rear = None
    
    def enqueue(self, data):
        new_node = ListNode(data)
        if not self.rear:
            self.front = new_node
            self.rear = new_node
            return
        self.rear.next = new_node
        self.rear = new_node

        self.front = self.front.next
        if not self.front:
            self.rear = None
        return data
```

```python
class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = {}
        self.head = DoublyListNode()
        self.tail = DoublyListNode()
        self.head.next = self.tail
        self.tail.prev = self.head
    
    def get(self, key):
        if key in self.cache:
            node = self.cache[key]
            self._remove(node)
            self._add(node)
            return node.value
        return -1
    
    def put(self, key, value):
        if key in self.cache:
            self._remove(self.cache[key])
        
        node = DoublyListNode(key, value)
        self.cache[key] = node
        self._add(node)
        
        if len(self.cache) > self.capacity:
            old_node = self.head.next
            self._remove(old_node)
            del self.cache[old_node.key]
    
    def _remove(self, node):
        prev_node = node.prev
        next_node = node.next
        prev_node.next = next_node
        next_node.prev = prev_node
    
    def _add(self, node):
        prev_node = self.tail.prev
        prev_node.next = node
        node.prev = prev_node
        node.next = self.tail
        self.tail.prev = node
```

## 栈

### 什么是栈

栈是一种**后进先出**（LIFO, Last In First Out）的线性数据结构。就像一摞盘子，你只能从最上面放盘子或取盘子。

### 栈的特性

1. **后进先出**：最后进入的元素最先被取出
2. **受限操作**：只能在栈顶进行插入和删除
3. **单端操作**：所有操作都在栈顶进行

### 栈的基本操作

#### 入栈（Push）

将元素压入栈顶。

```python
def push(stack, item):
    """入栈操作"""
    stack.append(item)
    return stack

# 使用示例
my_stack = []
push(my_stack, 10)
push(my_stack, 20)
push(my_stack, 30)
print(my_stack)  # [10, 20, 30]
```

时间复杂度：O(1)

#### 出栈（Pop）

从栈顶弹出元素。

```python
def pop(stack):
    """出栈操作"""
    if not stack:
        raise IndexError("栈为空")
    return stack.pop()

# 使用示例
my_stack = [10, 20, 30]
print(pop(my_stack))  # 30
print(pop(my_stack))  # 20
print(my_stack)       # [10]
```

时间复杂度：O(1)

#### 查看栈顶（Peek）

查看栈顶元素但不弹出。

```python
def peek(stack):
    """查看栈顶元素"""
    if not stack:
        raise IndexError("栈为空")
    return stack[-1]

# 使用示例

print(my_stack)        # [10, 20, 30]
```

时间复杂度：O(1)

#### 判断栈空（isEmpty）

检查栈是否为空。

```python

    """判断栈是否为空"""
```

### 栈的实现

#### 使用列表实现

```python
class Stack:
    def __init__(self):
        self.items = []
    
    def push(self, item):
        """入栈"""
        self.items.append(item)
```

## 队列

### 什么是队列

队列是一种**先进先出**（FIFO, First In First Out）的线性数据结构。就像排队买票，先来的人先买票。

### 队列的特性

1. **先进先出**：最先进入的元素最先被取出
2. **受限操作**：只能在队尾插入，队头删除
3. **双端操作**：插入和删除在不同端进行

```python
from collections import deque

def bfs(graph, start):
    """广度优先搜索"""
    visited = set()
    queue = deque([start])
    result = []
    
    while queue:
        vertex = queue.popleft()
        if vertex not in visited:
            visited.add(vertex)
            result.append(vertex)
            
            # 添加未访问的邻居
            for neighbor in graph[vertex]:
                if neighbor not in visited:
                    queue.append(neighbor)
    
    return result

# 使用示例

    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E']
}

print(bfs(graph, 'A'))  # ['A', 'B', 'C', 'D', 'E', 'F']
```

```python
from collections import deque

def max_sliding_window(nums, k):
    """滑动窗口最大值"""
    if not nums or k <= 0:
        return []
    
    result = []
    deque_window = deque()  # 存储索引
    
    for i in range(len(nums)):
        # 移除超出窗口的元素
        while deque_window and deque_window[0] <= i - k:
            deque_window.popleft()
        
        # 移除比当前元素小的元素
        while deque_window and nums[deque_window[-1]] < nums[i]:
            deque_window.pop()
        
        deque_window.append(i)
        
        # 记录最大值
        if i >= k - 1:
            result.append(nums[deque_window[0]])
    
    return result

# 使用示例
```

```python
        """判断是否为空"""
```

## 什么是哈希表

哈希表（Hash Table）是一种基于键值对（Key-Value）存储的数据结构，通过哈希函数将键映射到存储位置，实现快速的数据查找、插入和删除。

### 哈希表的特性

1. **快速查找**：平均时间复杂度为 O(1)
2. **键值对存储**：通过键直接访问对应的值
3. **无序存储**：数据在表中没有特定的顺序
4. **唯一键**：每个键必须是唯一的

## 哈希函数

### 哈希函数的作用

哈希函数将输入的键转换为数组索引，决定数据在哈希表中的存储位置。

### 理想的哈希函数

1. **确定性**：相同的输入总是产生相同的输出
2. **均匀分布**：将键均匀分布到所有可能的索引
3. **高效计算**：计算速度快
4. **低冲突率**：尽量减少哈希冲突

### 简单的哈希函数

```python
def simple_hash(key, size):
    """简单的哈希函数"""
    if isinstance(key, int):
        return key % size
    elif isinstance(key, str):
        hash_value = 0
        for char in key:
            hash_value += ord(char)
        return hash_value % size
    else:
        return hash(key) % size

# 使用示例
print(simple_hash(42, 10))      # 2
print(simple_hash("hello", 10))  # 取决于字符串的哈希值
print(simple_hash(100, 10))     # 0
```

## 哈希冲突

### 什么是哈希冲突

当两个不同的键通过哈希函数映射到相同的索引时，就发生了哈希冲突。

### 冲突解决方法

#### 1. 链地址法（Separate Chaining）

每个哈希表位置维护一个链表，冲突的元素都存储在同一个链表中。

```python
class HashTableChaining:
    def __init__(self, size=10):
        self.size = size
        self.table = [[] for _ in range(size)]
    
    def _hash(self, key):
        return hash(key) % self.size
    
    def put(self, key, value):
        """插入键值对"""
        index = self._hash(key)
        
        # 检查键是否已存在
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index][i] = (key, value)
                return
        
        # 键不存在，添加新键值对
        self.table[index].append((key, value))
    
    def get(self, key):
        """获取键对应的值"""
        index = self._hash(key)
        
        for k, v in self.table[index]:
            if k == key:
                return v
        
        raise KeyError(f"键 '{key}' 不存在")
    
    def remove(self, key):
        """删除键值对"""
        index = self._hash(key)
        
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index].pop(i)
                return
        
        raise KeyError(f"键 '{key}' 不存在")
    
    def display(self):
        """显示哈希表内容"""
        for i, bucket in enumerate(self.table):
            print(f"索引 {i}: {bucket}")
```

#### 2. 开放寻址法（Open Addressing）

当发生冲突时，寻找下一个可用的位置。

```python
class HashTableOpenAddressing:
    def __init__(self, size=10):
        self.size = size
        self.keys = [None] * size
        self.values = [None] * size
    
    def _hash(self, key):
        return hash(key) % self.size
    
    def _probe(self, key):
        """线性探测"""
        index = self._hash(key)
        i = 0
        while self.keys[index] is not None and self.keys[index] != key:
            index = (index + 1) % self.size
            i += 1
            if i >= self.size:
                raise Exception("哈希表已满")
        return index
    
    def put(self, key, value):
        """插入键值对"""
        index = self._probe(key)
        self.keys[index] = key
        self.values[index] = value
    
    def get(self, key):
        """获取键对应的值"""
        index = self._probe(key)
        if self.keys[index] == key:
            return self.values[index]
        raise KeyError(f"键 '{key}' 不存在")
    
    def remove(self, key):
        """删除键值对"""
        index = self._probe(key)
        if self.keys[index] == key:
            self.keys[index] = None
            self.values[index] = None
        else:
            raise KeyError(f"键 '{key}' 不存在")
```

```python
    index = hash_function(key, hash_table.size)
    if hash_table.table[index] and hash_table.table[index][0] == key:
        return hash_table.table[index][1]
    return None
```

平均时间复杂度：O(1)

```python
        self.cache = {}

        """获取缓存值"""
```

## 哈希表的性能分析

### 时间复杂度

| 操作 | 平均情况 | 最坏情况 |
|------|----------|----------|
| 插入 | O(1) | O(n) |
| 查找 | O(1) | O(n) |
| 删除 | O(1) | O(n) |

### 影响性能的因素

1. **哈希函数质量**：好的哈希函数能减少冲突
2. **负载因子**：元素数量与哈希表大小的比值
3. **冲突解决策略**：不同的冲突解决方法性能不同
4. **数据分布**：数据的分布特征影响哈希效果

### 负载因子

```python
class LoadFactorHashTable:
    def __init__(self, initial_size=10, load_factor=0.75):
        self.size = initial_size
        self.load_factor = load_factor
        self.count = 0
        self.table = [[] for _ in range(self.size)]
    
    def _hash(self, key):
        return hash(key) % self.size
    
    def _resize(self):
        """调整哈希表大小"""
        old_table = self.table
        self.size *= 2
        self.table = [[] for _ in range(self.size)]
        self.count = 0
        
        for bucket in old_table:
            for key, value in bucket:
                self.put(key, value)
    
    def put(self, key, value):
        """插入键值对"""
        # 检查是否需要扩容
        if self.count / self.size >= self.load_factor:
            self._resize()
        
        index = self._hash(key)
        
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index][i] = (key, value)
                return
        
        self.table[index].append((key, value))
        self.count += 1
```

## 哈希表的优缺点

### 优点

1. **快速访问**：平均 O(1) 的查找、插入、删除
2. **灵活的键类型**：可以使用各种可哈希类型作为键
3. **动态大小**：可以根据需要动态调整大小
4. **简单易用**：API 简单直观

### 缺点

1. **无序性**：不保持元素的插入顺序
2. **冲突处理**：冲突处理可能影响性能
3. **空间开销**：需要额外的空间来避免冲突
4. **哈希函数依赖**：性能依赖于哈希函数的质量

## 什么是树

树是一种非线性数据结构，由节点和边组成，具有层次结构。树结构模拟了现实中的层次关系，如文件系统、组织架构等。

### 树的基本特性

1. **层次结构**：节点之间存在父子关系
2. **唯一根节点**：每个树有且仅有一个根节点
3. **无环结构**：节点之间不存在环路
4. **递归定义**：子树也是树结构

### 树的基本概念

- **根节点**：树的顶层节点，没有父节点
- **叶子节点**：没有子节点的节点
- **内部节点**：既有父节点又有子节点的节点
- **父节点**：直接连接到下层节点的节点
- **子节点**：直接连接到上层节点的节点
- **兄弟节点**：具有相同父节点的节点
- **节点深度**：从根节点到该节点的边数
- **节点高度**：从该节点到最远叶子节点的边数
- **树的高度**：根节点的高度
- **树的度**：节点中最大的子节点数

## 二叉树

### 什么是二叉树

二叉树是每个节点最多有两个子节点的树结构，分别称为左子节点和右子节点。

### 二叉树的特性

1. **每个节点最多有两个子节点**
2. **子节点有左右之分**
3. **第 i 层最多有 2^(i-1) 个节点**
4. **高度为 h 的二叉树最多有 2^h - 1 个节点**

### 二叉树的实现

```python
class TreeNode:
    def __init__(self, val=0):
        self.val = val
        self.left = None
        self.right = None

class BinaryTree:
    def __init__(self):
        self.root = None
    
    def insert(self, val):
        """插入节点（按层次插入）"""
        if not self.root:
            self.root = TreeNode(val)
            return
        
        queue = [self.root]
        while queue:
            node = queue.pop(0)
            
            if not node.left:
                node.left = TreeNode(val)
                return
            else:
                queue.append(node.left)
            
            if not node.right:
                node.right = TreeNode(val)
                return
            else:
                queue.append(node.right)
```

### 二叉树的遍历

#### 前序遍历（根-左-右）

```python
def preorder_traversal(root):
    """前序遍历：根 -> 左 -> 右"""
    if not root:
        return []
    
    result = []
    stack = [root]
    
    while stack:
        node = stack.pop()
        result.append(node.val)
        
        # 先压入右子节点，再压入左子节点
        if node.right:
            stack.append(node.right)
        if node.left:
            stack.append(node.left)
    
    return result

# 递归版本
def preorder_recursive(root):
    """前序遍历递归版本"""
    if not root:
        return []
    
    return [root.val] + preorder_recursive(root.left) + preorder_recursive(root.right)
```

#### 中序遍历（左-根-右）

```python
def inorder_traversal(root):
    """中序遍历：左 -> 根 -> 右"""
    if not root:
        return []
    
    result = []
    stack = []
    current = root
    
    while current or stack:
        # 遍历到最左边的节点
        while current:
            stack.append(current)
            current = current.left
        
        current = stack.pop()
        result.append(current.val)
        current = current.right
    
    return result

# 递归版本
def inorder_recursive(root):
    """中序遍历递归版本"""
    if not root:
        return []
    
    return inorder_recursive(root.left) + [root.val] + inorder_recursive(root.right)
```

#### 后序遍历（左-右-根）

```python
def postorder_traversal(root):
    """后序遍历：左 -> 右 -> 根"""
    if not root:
        return []
    
    result = []
    stack = [root]
    
    while stack:
        node = stack.pop()
        result.append(node.val)
        
        if node.left:
            stack.append(node.left)
        if node.right:
            stack.append(node.right)
    
    return result[::-1]

# 递归版本
def postorder_recursive(root):
    """后序遍历递归版本"""
    if not root:
        return []
    
    return postorder_recursive(root.left) + postorder_recursive(root.right) + [root.val]
```

#### 层次遍历（广度优先）

```python
from collections import deque

def level_order_traversal(root):
    """层次遍历（广度优先）"""
    if not root:
        return []
    
    result = []
    queue = deque([root])
    
    while queue:
        level_size = len(queue)
        level_nodes = []
        
        for _ in range(level_size):
            node = queue.popleft()
            level_nodes.append(node.val)
            
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        
        result.append(level_nodes)
    
    return result
```

## 二叉搜索树

### 什么是二叉搜索树

二叉搜索树（BST）是一种特殊的二叉树，对于每个节点：
- 左子树的所有节点值都小于该节点值
- 右子树的所有节点值都大于该节点值
- 左右子树也都是二叉搜索树

### 二叉搜索树的实现

```python
class BSTNode:
    def __init__(self, val=0):
        self.val = val
        self.left = None
        self.right = None

class BinarySearchTree:
    def __init__(self):
        self.root = None
    
    def insert(self, val):
        """插入节点"""
        if not self.root:
            self.root = BSTNode(val)
            return
        
        self._insert_recursive(self.root, val)
    
    def _insert_recursive(self, node, val):
        """递归插入"""
        if val < node.val:
            if node.left is None:
                node.left = BSTNode(val)
            else:
                self._insert_recursive(node.left, val)
        else:
            if node.right is None:
                node.right = BSTNode(val)
            else:
                self._insert_recursive(node.right, val)
    
    def search(self, val):
        """查找节点"""
        return self._search_recursive(self.root, val)
    
    def _search_recursive(self, node, val):
        """递归查找"""
        if not node or node.val == val:
            return node
        
        if val < node.val:
            return self._search_recursive(node.left, val)
        else:
            return self._search_recursive(node.right, val)
    
    def delete(self, val):
        """删除节点"""
        self.root = self._delete_recursive(self.root, val)
    
    def _delete_recursive(self, node, val):
        """递归删除"""
        if not node:
            return None
        
        if val < node.val:
            node.left = self._delete_recursive(node.left, val)
        elif val > node.val:
            node.right = self._delete_recursive(node.right, val)
        else:
            # 找到要删除的节点
            # 情况1：叶子节点
            if not node.left and not node.right:
                return None
            # 情况2：只有一个子节点
            elif not node.left:
                return node.right
            elif not node.right:
                return node.left
            # 情况3：有两个子节点
            else:
                # 找到右子树的最小值节点
                min_node = self._find_min(node.right)
                node.val = min_node.val
                node.right = self._delete_recursive(node.right, min_node.val)
        
        return node
    
    def _find_min(self, node):
        """找到最小值节点"""
        while node.left:
            node = node.left
        return node
```

## 平衡二叉树

### 为什么需要平衡二叉树

普通二叉搜索树在最坏情况下会退化为链表，导致操作复杂度变为 O(n)。平衡二叉树通过保持树的平衡来确保操作效率。

### AVL树

AVL树是一种自平衡二叉搜索树，对于每个节点，其左右子树的高度差不超过1。

```python
class AVLNode:
    def __init__(self, val=0):
        self.val = val
        self.left = None
        self.right = None
        self.height = 1

class AVLTree:
    def __init__(self):
        self.root = None
    
    def height(self, node):
        """获取节点高度"""
        if not node:
            return 0
        return node.height
    
    def balance_factor(self, node):
        """计算平衡因子"""
        if not node:
            return 0
        return self.height(node.left) - self.height(node.right)
    
    def right_rotate(self, y):
        """右旋转"""
        x = y.left
        T2 = x.right
        
        x.right = y
        y.left = T2
        
        y.height = max(self.height(y.left), self.height(y.right)) + 1
        x.height = max(self.height(x.left), self.height(x.right)) + 1
        
        return x
    
    def left_rotate(self, x):
        """左旋转"""
        y = x.right
        T2 = y.left
        
        y.left = x
        x.right = T2
        
        x.height = max(self.height(x.left), self.height(x.right)) + 1
        y.height = max(self.height(y.left), self.height(y.right)) + 1
        
        return y
    
    def insert(self, val):
        """插入节点"""
        self.root = self._insert(self.root, val)
    
    def _insert(self, node, val):
        """递归插入并平衡"""
        if not node:
            return AVLNode(val)
        
        if val < node.val:
            node.left = self._insert(node.left, val)
        else:
            node.right = self._insert(node.right, val)
        
        node.height = max(self.height(node.left), self.height(node.right)) + 1
        
        balance = self.balance_factor(node)
        
        # 左左情况
        if balance > 1 and val < node.left.val:
            return self.right_rotate(node)
        
        # 右右情况
        if balance < -1 and val > node.right.val:
            return self.left_rotate(node)
        
        # 左右情况
        if balance > 1 and val > node.left.val:
            node.left = self.left_rotate(node.left)
            return self.right_rotate(node)
        
        # 右左情况
        if balance < -1 and val < node.right.val:
            node.right = self.right_rotate(node.right)
            return self.left_rotate(node)
        
        return node
```

```python
class ExpressionTree:
    def __init__(self):
        self.root = None
    
    def build(self, postfix):
        """根据后缀表达式构建表达式树"""
        stack = []
        
        for token in postfix:
            if token.isdigit():
                stack.append(TreeNode(int(token)))
            else:
                node = TreeNode(token)
                node.right = stack.pop()
                node.left = stack.pop()
                stack.append(node)
        
        self.root = stack.pop()
    
    def evaluate(self):
        """计算表达式树的值"""
        return self._evaluate(self.root)
    
    def _evaluate(self, node):
        """递归计算"""
        if not node:
            return 0
        
        if not node.left and not node.right:
            return int(node.val)
        
        left_val = self._evaluate(node.left)
        right_val = self._evaluate(node.right)
        
        if node.val == '+':
            return left_val + right_val
        elif node.val == '-':
            return left_val - right_val
        elif node.val == '*':
            return left_val * right_val
        elif node.val == '/':
            return left_val // right_val
    
    def inorder(self):
        """中序遍历（带括号）"""
        return self._inorder(self.root)
    
    def _inorder(self, node):
        """递归中序遍历"""
        if not node:
            return ""
        
        if not node.left and not node.right:
            return str(node.val)
        
        left = self._inorder(node.left)
        right = self._inorder(node.right)
        
        return f"({left}{node.val}{right})"

# 使用示例
expr_tree = ExpressionTree()
expr_tree.build(["3", "4", "+", "2", "*"])
print(expr_tree.inorder())    # ((3+4)*2)
print(expr_tree.evaluate())   # 14
```

```python
        components = path.split('/')
        node = self.root
        
        for i, component in enumerate(components[:-1]):
            if component not in node.children:
                return False
            node = node.children[component]
        
        file_name = components[-1]
        if file_name in node.children:
            return False
        
        is_file = i == len(components) - 2
        node.children[file_name] = FileNode(file_name, is_file, value)
        return True
    
    def get(self, path):
        """获取文件大小"""
        components = path.split('/')
        node = self.root
        
        for component in components:
            if component not in node.children:
                return -1
            node = node.children[component]
        
        return node.size if node.is_file else -1
```

```python
import heapq
from collections import Counter

class HuffmanNode:
    def __init__(self, char=None, freq=0, left=None, right=None):
        self.char = char
        self.freq = freq
        self.left = left
        self.right = right
    
    def __lt__(self, other):
        return self.freq < other.freq

def build_huffman_tree(text):
    """构建霍夫曼树"""
    if not text:
        return None
    
    # 统计字符频率
    freq = Counter(text)
    
    # 创建优先队列
    heap = [HuffmanNode(char, freq) for char, freq in freq.items()]
    heapq.heapify(heap)
    
    # 构建霍夫曼树
    while len(heap) > 1:
        left = heapq.heappop(heap)
        right = heapq.heappop(heap)
        merged = HuffmanNode(freq=left.freq + right.freq, left=left, right=right)
        heapq.heappush(heap, merged)
    
    return heap[0]

def generate_codes(node, current_code="", code_map=None):
    """生成霍夫曼编码"""
    if code_map is None:
        code_map = {}
    
    if node is None:
        return code_map
    
    if node.char is not None:
        code_map[node.char] = current_code
        return code_map
    
    generate_codes(node.left, current_code + "0", code_map)
    generate_codes(node.right, current_code + "1", code_map)
    
    return code_map

# 使用示例
```

## 什么是堆

堆是一种特殊的树形数据结构，满足堆性质。堆通常使用完全二叉树来实现，并且可以用数组高效存储。

### 堆的特性

1. **完全二叉树**：除了最后一层，其他层都被完全填满
2. **堆性质**：父节点与子节点之间满足特定关系
3. **数组存储**：可以用数组高效存储和访问

### 堆的类型

#### 最大堆（Max Heap）

- 每个节点的值都大于或等于其子节点的值
- 根节点是最大值

#### 最小堆（Min Heap）

- 每个节点的值都小于或等于其子节点的值
- 根节点是最小值

## 堆的数组表示

堆可以用数组来表示，对于索引为 i 的节点：
- 父节点索引：(i - 1) // 2
- 左子节点索引：2 * i + 1
- 右子节点索引：2 * i + 2

## 堆的基本操作

### 堆化（Heapify）

将一个无序数组调整为堆结构。

```python
def heapify(arr, n, i):
    """堆化操作（最大堆）"""
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2
    
    # 检查左子节点是否大于当前最大值
    if left < n and arr[left] > arr[largest]:
        largest = left
    
    # 检查右子节点是否大于当前最大值
    if right < n and arr[right] > arr[largest]:
        largest = right
    
    # 如果最大值不是当前节点，交换并继续堆化
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)
```

## 堆的实现

### 最大堆实现

```python
class MaxHeap:
    def __init__(self):
        self.heap = []
    
    def parent(self, i):
        """获取父节点索引"""
        return (i - 1) // 2
    
    def left_child(self, i):
        """获取左子节点索引"""
        return 2 * i + 1
    
    def right_child(self, i):
        """获取右子节点索引"""
        return 2 * i + 2
    
    def insert(self, val):
        """插入元素"""
        self.heap.append(val)
        self._sift_up(len(self.heap) - 1)
    
    def _sift_up(self, i):
        """向上调整"""
        while i > 0 and self.heap[self.parent(i)] < self.heap[i]:
            self.heap[self.parent(i)], self.heap[i] = self.heap[i], self.heap[self.parent(i)]
            i = self.parent(i)
    
    def extract_max(self):
        """提取最大值"""
        if not self.heap:
            raise IndexError("堆为空")
        
        if len(self.heap) == 1:
            return self.heap.pop()
        
        max_val = self.heap[0]
        self.heap[0] = self.heap.pop()
        self._sift_down(0)
        
        return max_val
    
    def _sift_down(self, i):
        """向下调整"""
        n = len(self.heap)
        
        while True:
            left = self.left_child(i)
            right = self.right_child(i)
            largest = i
            
            if left < n and self.heap[left] > self.heap[largest]:
                largest = left
            
            if right < n and self.heap[right] > self.heap[largest]:
                largest = right
            
            if largest != i:
                self.heap[i], self.heap[largest] = self.heap[largest], self.heap[i]
                i = largest
            else:
                break
    
    def peek(self):
        """查看最大值"""
        if not self.heap:
            raise IndexError("堆为空")
        return self.heap[0]
    
    def size(self):
        """堆的大小"""
        return len(self.heap)
    
    def is_empty(self):
        """判断堆是否为空"""
        return len(self.heap) == 0
```

```python
    """堆排序"""
    n = len(arr)

    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)
```

```python
import heapq

def top_k_elements(arr, k):
    """找出数组中最大的 k 个元素"""
    if k <= 0:
        return []
    if k >= len(arr):
        return arr
    
    # 使用最小堆保持 k 个最大元素
    heap = arr[:k]
    heapq.heapify(heap)
    
    for num in arr[k:]:
        if num > heap[0]:
            heapq.heappop(heap)
            heapq.heappush(heap, num)
    
    return sorted(heap, reverse=True)
```

```python
import heapq

def merge_sorted_arrays(arrays):
    """合并多个有序数组"""
    heap = []
    result = []
    
    # 将每个数组的第一个元素放入堆中
    for i, arr in enumerate(arrays):
        if arr:
            heapq.heappush(heap, (arr[0], i, 0))
    
    while heap:
        val, array_idx, element_idx = heapq.heappop(heap)
        result.append(val)
        
        # 将同一数组的下一个元素放入堆中
        if element_idx + 1 < len(arrays[array_idx]):
            next_val = arrays[array_idx][element_idx + 1]
            heapq.heappush(heap, (next_val, array_idx, element_idx + 1))
    
    return result

# 使用示例
arrays = [

    [1, 3, 4],
    [2, 6]
]
```

### 应用5：中位数维护

```python
import heapq

class MedianFinder:
    def __init__(self):
        self.max_heap = []  # 存储较小的一半（最大堆）
        self.min_heap = []  # 存储较大的一半（最小堆）
    
    def add_num(self, num):
        """添加数字"""
        # 先放入最大堆
        heapq.heappush(self.max_heap, -num)
        
        # 确保最大堆的最大值 <= 最小堆的最小值
        if self.min_heap and -self.max_heap[0] > self.min_heap[0]:
            val = -heapq.heappop(self.max_heap)
            heapq.heappush(self.min_heap, val)
        
        # 平衡两个堆的大小
        if len(self.max_heap) > len(self.min_heap) + 1:
            val = -heapq.heappop(self.max_heap)
            heapq.heappush(self.min_heap, val)
        elif len(self.min_heap) > len(self.max_heap):
            val = heapq.heappop(self.min_heap)
            heapq.heappush(self.max_heap, -val)
    
    def find_median(self):
        """查找中位数"""
        if not self.max_heap and not self.min_heap:
            raise ValueError("没有数据")
        
        if len(self.max_heap) == len(self.min_heap):
            return (-self.max_heap[0] + self.min_heap[0]) / 2
        else:
            return -self.max_heap[0]

# 使用示例
mf = MedianFinder()
mf.add_num(1)
mf.add_num(2)
print(mf.find_median())  # 1.5
mf.add_num(3)
print(mf.find_median())  # 2
```

## 堆的优缺点

### 优点

1. **快速获取极值**：O(1) 时间获取最大值或最小值
2. **高效插入删除**：O(log n) 时间插入和删除
3. **空间效率高**：使用数组存储，空间利用率高
4. **实现简单**：相对容易实现和理解

### 缺点

1. **查找效率低**：查找特定元素需要 O(n) 时间
2. **不支持范围查询**：无法高效进行范围查询
3. **顺序访问差**：无法按顺序遍历所有元素

## 什么是图

图是一种非线性数据结构，由顶点（Vertex）和边（Edge）组成,用于表示对象之间的关系。图广泛应用于社交网络、地图导航、网络拓扑等领域。

### 图的基本概念

- **顶点（Vertex）**：图中的节点
- **边（Edge）**：连接顶点的线
- **度（Degree）**：与顶点相连的边的数量
- **路径（Path）**：顶点之间的连接序列
- **环（Cycle）**：起点和终点相同的路径
- **连通图**：任意两个顶点之间都有路径
- **权重（Weight）**：边上的数值，表示距离、成本等

### 图的分类

#### 按边的方向分类

1. **无向图**：边没有方向
2. **有向图**：边有方向

#### 按边的权重分类

1. **无权图**：边没有权重
2. **有权图**：边有权重

#### 按边的数量分类

1. **稀疏图**：边的数量远小于顶点数量的平方
2. **稠密图**：边的数量接近顶点数量的平方

## 图的表示方法

### 邻接矩阵

使用二维矩阵表示图，矩阵中的元素表示顶点之间是否有边。

```python
class GraphMatrix:
    def __init__(self, num_vertices, directed=False):
        self.num_vertices = num_vertices
        self.directed = directed
        self.matrix = [[0] * num_vertices for _ in range(num_vertices)]
    
    def add_edge(self, u, v, weight=1):
        """添加边"""
        if 0 <= u < self.num_vertices and 0 <= v < self.num_vertices:
            self.matrix[u][v] = weight
            if not self.directed:
                self.matrix[v][u] = weight
    
    def remove_edge(self, u, v):
        """删除边"""
        if 0 <= u < self.num_vertices and 0 <= v < self.num_vertices:
            self.matrix[u][v] = 0
            if not self.directed:
                self.matrix[v][u] = 0
    
    def has_edge(self, u, v):
        """检查边是否存在"""
        if 0 <= u < self.num_vertices and 0 <= v < self.num_vertices:
            return self.matrix[u][v] != 0
        return False
    
    def get_neighbors(self, v):
        """获取顶点的邻居"""
        if 0 <= v < self.num_vertices:
            neighbors = []
            for i in range(self.num_vertices):
                if self.matrix[v][i] != 0:
                    neighbors.append(i)
            return neighbors
        return []
    
    def display(self):
        """显示邻接矩阵"""
        for row in self.matrix:
            print(row)

# 使用示例

```

### 邻接表

使用字典或列表表示图，每个顶点存储其相邻的顶点。

```python
class GraphAdjList:
    def __init__(self, directed=False):
        self.graph = {}
        self.directed = directed
    
    def add_vertex(self, vertex):
        """添加顶点"""
        if vertex not in self.graph:
            self.graph[vertex] = []
    
    def add_edge(self, u, v, weight=1):
        """添加边"""
        if u not in self.graph:
            self.add_vertex(u)
        if v not in self.graph:
            self.add_vertex(v)
        
        self.graph[u].append((v, weight))
        if not self.directed:
            self.graph[v].append((u, weight))
    
    def remove_edge(self, u, v):
        """删除边"""
        if u in self.graph and v in self.graph:
            self.graph[u] = [(neighbor, weight) for neighbor, weight in self.graph[u] if neighbor != v]
            if not self.directed:
                self.graph[v] = [(neighbor, weight) for neighbor, weight in self.graph[v] if neighbor != u]
    
    def has_edge(self, u, v):
        """检查边是否存在"""
        if u in self.graph:
            for neighbor, _ in self.graph[u]:
                if neighbor == v:
                    return True
        return False
    
    def get_neighbors(self, v):
        """获取顶点的邻居"""
        if v in self.graph:
            return [neighbor for neighbor, _ in self.graph[v]]
        return []
    
    def display(self):
        """显示邻接表"""
        for vertex in self.graph:
            print(f"{vertex}: {self.graph[vertex]}")

# 使用示例
```

## 图的遍历

### 深度优先搜索（DFS）

从起始顶点开始，沿着一条路径尽可能深入，无法继续时回溯。

```python
def dfs(graph, start, visited=None):
    """深度优先搜索"""
    if visited is None:
        visited = set()
    
    visited.add(start)
    print(start, end=" ")
    
    for neighbor in graph.get_neighbors(start):
        if neighbor not in visited:
            dfs(graph, neighbor, visited)
    
    return visited

# 迭代版本
def dfs_iterative(graph, start):
    """深度优先搜索迭代版本"""
    visited = set()
    stack = [start]
    
    while stack:
        vertex = stack.pop()
        if vertex not in visited:
            visited.add(vertex)
            print(vertex, end=" ")
            
            # 将邻居按相反顺序压入栈，保证顺序正确
            for neighbor in reversed(graph.get_neighbors(vertex)):
                if neighbor not in visited:
                    stack.append(neighbor)
    
    return visited
```

### 广度优先搜索（BFS）

从起始顶点开始，先访问所有相邻顶点，再访问相邻顶点的相邻顶点。

```python
from collections import deque

def bfs(graph, start):
    """广度优先搜索"""
    visited = set()
    queue = deque([start])
    visited.add(start)
    
    while queue:
        vertex = queue.popleft()
        print(vertex, end=" ")
        
        for neighbor in graph.get_neighbors(vertex):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    
    return visited
```

## 最短路径算法

### Dijkstra算法

用于计算图中从一个顶点到其他所有顶点的最短路径（适用于非负权重图）。

```python
import heapq

def dijkstra(graph, start):
    """Dijkstra最短路径算法"""
    distances = {vertex: float('infinity') for vertex in graph.graph}
    distances[start] = 0
    
    priority_queue = [(0, start)]
    visited = set()
    
    while priority_queue:
        current_distance, current_vertex = heapq.heappop(priority_queue)
        
        if current_vertex in visited:
            continue
        
        visited.add(current_vertex)
        
        for neighbor, weight in graph.graph[current_vertex]:
            distance = current_distance + weight
            
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))
    
    return distances

# 使用示例
graph = GraphAdjList()
graph.add_edge(0, 1, 4)
graph.add_edge(0, 2, 2)
graph.add_edge(1, 2, 1)
graph.add_edge(1, 3, 5)
graph.add_edge(2, 3, 8)
graph.add_edge(2, 4, 10)
graph.add_edge(3, 4, 2)

distances = dijkstra(graph, 0)
print(distances)  # {0: 0, 1: 3, 2: 2, 3: 8, 4: 10}
```

### Floyd-Warshall算法

计算图中所有顶点对之间的最短路径。

```python
def floyd_warshall(graph):
    """Floyd-Warshall算法"""
    vertices = list(graph.graph.keys())
    n = len(vertices)
    
    # 初始化距离矩阵
    dist = [[float('infinity')] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    
    # 填充初始距离
    for i in range(n):
        for j, weight in graph.graph[vertices[i]]:
            dist[i][j] = weight
    
    # 计算最短路径
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    
    return dist
```

## 最小生成树

### Prim算法

从一个顶点开始，逐步添加边，直到生成最小生成树。

```python
def prim(graph, start):
    """Prim最小生成树算法"""
    mst = []
    visited = set([start])
    edges = []
    
    # 添加起始顶点的所有边
    for neighbor, weight in graph.graph[start]:
        heapq.heappush(edges, (weight, start, neighbor))
    
    while edges and len(visited) < len(graph.graph):
        weight, u, v = heapq.heappop(edges)
        
        if v not in visited:
            visited.add(v)
            mst.append((u, v, weight))
            
            # 添加新顶点的所有边
            for neighbor, w in graph.graph[v]:
                if neighbor not in visited:
                    heapq.heappush(edges, (w, v, neighbor))
    
    return mst
```

### Kruskal算法

按权重从小到大选择边，避免形成环，直到生成最小生成树。

```python
class UnionFind:
    def __init__(self, vertices):
        self.parent = {v: v for v in vertices}
        self.rank = {v: 0 for v in vertices}
    
    def find(self, item):
        """查找根节点"""
        while self.parent[item] != item:
            item = self.parent[item]
        return item
    
    def union(self, set1, set2):
        """合并两个集合"""
        root1 = self.find(set1)
        root2 = self.find(set2)
        
        if root1 != root2:
            if self.rank[root1] > self.rank[root2]:
                self.parent[root2] = root1
            else:
                self.parent[root1] = root2
                if self.rank[root1] == self.rank[root2]:
                    self.rank[root2] += 1

def kruskal(graph):
    """Kruskal最小生成树算法"""
    edges = []
    for u in graph.graph:
        for v, weight in graph.graph[u]:
            edges.append((weight, u, v))
    
    edges.sort()  # 按权重排序
    vertices = list(graph.graph.keys())
    uf = UnionFind(vertices)
    mst = []
    
    for weight, u, v in edges:
        if uf.find(u) != uf.find(v):
            uf.union(u, v)
            mst.append((u, v, weight))
    
    return mst
```

## 拓扑排序

对有向无环图（DAG）进行排序，使得对于每一条边 u→v，u 都在 v 之前。

```python
def topological_sort(graph):
    """拓扑排序"""
    in_degree = {v: 0 for v in graph.graph}
    
    # 计算入度
    for u in graph.graph:
        for v, _ in graph.graph[u]:
            in_degree[v] += 1
    
    # 找到入度为0的顶点
    queue = deque([v for v in in_degree if in_degree[v] == 0])
    result = []
    
    while queue:
        vertex = queue.popleft()
        result.append(vertex)
        
        for neighbor, _ in graph.graph[vertex]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)
    
    if len(result) != len(graph.graph):
        return None  # 图中有环
    
    return result
```

## 什么是搜索算法

搜索算法用于在数据结构中查找特定元素或满足特定条件的元素。搜索算法的效率直接影响程序的性能。

### 搜索算法的分类

## 线性搜索

### 基本原理

线性搜索是最简单的搜索算法，从数据结构的第一个元素开始，逐个检查直到找到目标元素或遍历完所有元素。

### 线性搜索实现

```python
def linear_search(arr, target):
    """线性搜索"""
    for i, element in enumerate(arr):
        if element == target:
            return i  # 返回索引
    return -1  # 未找到

# 使用示例
arr = [64, 34, 25, 12, 22, 11, 90]
target = 22
result = linear_search(arr, target)
print(f"元素 {target} 的索引是: {result}")  # 元素 22 的索引是: 4
```

### 线性搜索的复杂度

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)
- **适用场景**：无序数据、小规模数据

### 线性搜索的优化

#### 哨兵线性搜索

```python
def linear_search_sentinel(arr, target):
    """哨兵线性搜索"""
    n = len(arr)
    last = arr[n - 1]  # 保存最后一个元素
    arr[n - 1] = target  # 设置哨兵
    
    i = 0
    while arr[i] != target:
        i += 1
    
    arr[n - 1] = last  # 恢复最后一个元素
    
    if i < n - 1 or arr[n - 1] == target:
        return i
    return -1
```

## 二分搜索

### 基本原理

二分搜索只能在有序数组中使用。它通过比较中间元素与目标值，每次将搜索范围减半，直到找到目标或确定不存在。

### 二分搜索实现

#### 迭代版本

```python
def binary_search(arr, target):
    """二分搜索迭代版本"""
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2
        
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return -1  # 未找到

# 使用示例
arr = [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]
target = 23
result = binary_search(arr, target)
print(f"元素 {target} 的索引是: {result}")  # 元素 23 的索引是: 5
```

#### 递归版本

```python
def binary_search_recursive(arr, target, left, right):
    """二分搜索递归版本"""
    if left > right:
        return -1
    
    mid = (left + right) // 2
    
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binary_search_recursive(arr, target, mid + 1, right)
    else:
        return binary_search_recursive(arr, target, left, mid - 1)

# 使用示例
arr = [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]
target = 23
result = binary_search_recursive(arr, target, 0, len(arr) - 1)
print(f"元素 {target} 的索引是: {result}")
```

### 二分搜索的复杂度

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1) 迭代版本，O(log n) 递归版本
- **适用场景**：有序数组、大规模数据

### 二分搜索的变种

#### 查找第一个出现的元素

```python
def binary_search_first(arr, target):
    """查找第一个出现的元素"""

    result = -1
    
    while left <= right:

            result = mid
            right = mid - 1  # 继续在左半部分搜索

            left = mid + 1
        else:
            right = mid - 1
    
    return result
```

## 插值搜索

### 基本原理

插值搜索是二分搜索的改进版本，根据目标值在数据分布中的位置来预测其可能的位置。

### 插值搜索实现

```python
def interpolation_search(arr, target):
    """插值搜索"""
    left, right = 0, len(arr) - 1
    
    while left <= right and target >= arr[left] and target <= arr[right]:
        if left == right:
            if arr[left] == target:
                return left
            return -1
        
        # 插值公式
        pos = left + ((target - arr[left]) * (right - left)) // (arr[right] - arr[left])
        
        if arr[pos] == target:
            return pos
        elif arr[pos] < target:
            left = pos + 1
        else:
            right = pos - 1
    
    return -1

# 使用示例

```

## 哈希搜索

### 基本原理

哈希搜索使用哈希函数将键映射到存储位置，实现 O(1) 时间复杂度的查找。

### 哈希搜索实现

```python
class HashSearch:
    def __init__(self, size=10):
        self.size = size
        self.table = [[] for _ in range(size)]
    
    def _hash(self, key):
        return hash(key) % self.size
    
    def insert(self, key, value):
        """插入键值对"""
        index = self._hash(key)
        
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index][i] = (key, value)
                return
        
        self.table[index].append((key, value))
    
    def search(self, key):
        """搜索键"""
        index = self._hash(key)
        
        for k, v in self.table[index]:
            if k == key:
                return v
        
        return None

# 使用示例
hs = HashSearch()
hs.insert("name", "Alice")
hs.insert("age", 25)
hs.insert("city", "Beijing")

print(hs.search("name"))  # Alice
print(hs.search("age"))   # 25
```

### 哈希搜索的复杂度

- **时间复杂度**：平均 O(1)，最坏 O(n)
- **空间复杂度**：O(n)
- **适用场景**：需要快速查找的场景

```python
def bst_search(root, target):
    """二叉搜索树搜索"""
    if not root or root.val == target:
        return root
    
    if target < root.val:
        return bst_search(root.left, target)
    else:
        return bst_search(root.right, target)

# 迭代版本
def bst_search_iterative(root, target):
    """二叉搜索树搜索迭代版本"""
    while root and root.val != target:
        if target < root.val:
            root = root.left
        else:
            root = root.right
    return root
```

## 什么是排序算法

排序算法是将一组数据按照特定顺序（升序或降序）重新排列的算法。排序是计算机科学中最基本也是最重要的操作之一。

### 排序算法的分类

1. **比较排序**：通过比较元素大小进行排序
2. **非比较排序**：不通过比较元素大小进行排序
3. **内部排序**：所有数据都在内存中
4. **外部排序**：数据量太大，需要使用外部存储

### 排序算法的评估标准

- **时间复杂度**：算法执行时间
- **空间复杂度**：算法所需额外空间
- **稳定性**：相等元素的相对位置是否保持不变
- **适应性**：对部分有序数据的处理能力

## 简单排序算法

### 冒泡排序

#### 基本原理

冒泡排序通过重复遍历数组，比较相邻元素并交换位置，使较大的元素逐渐"冒泡"到数组末尾。

#### 冒泡排序实现

```python
def bubble_sort(arr):
    """冒泡排序"""
    n = len(arr)
    
    for i in range(n):
        # 标记本轮是否发生交换
        swapped = False
        
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        
        # 如果没有发生交换，说明已经有序
        if not swapped:
            break
    
    return arr

# 使用示例
arr = [64, 34, 25, 12, 22, 11, 90]
print("排序前:", arr)
bubble_sort(arr)
print("排序后:", arr)
```

#### 冒泡排序的复杂度

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)
- **稳定性**：稳定
- **适用场景**：小规模数据、教学演示

```python
def insertion_sort(arr):
```

## 高级排序算法

### 归并排序

#### 基本原理

归并排序采用分治策略，将数组分成两半，分别排序后合并。

#### 归并排序实现

```python
def merge_sort(arr):
    """归并排序"""
    if len(arr) <= 1:
        return arr
    
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    
    return merge(left, right)

def merge(left, right):
    """合并两个有序数组"""
    result = []
    i = j = 0
    
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    
    result.extend(left[i:])
    result.extend(right[j:])
    
    return result

# 使用示例
```

### 快速排序

#### 基本原理

快速排序选择一个基准元素，将数组分为小于基准和大于基准的两部分，递归排序。

#### 快速排序实现

```python
def quick_sort(arr):
    """快速排序"""
    if len(arr) <= 1:
        return arr
    
    pivot = arr[len(arr) // 2]  # 选择中间元素作为基准
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    
    return quick_sort(left) + middle + quick_sort(right)

# 原地版本
def quick_sort_inplace(arr, low, high):
    """快速排序原地版本"""
    if low < high:
        pi = partition(arr, low, high)
        quick_sort_inplace(arr, low, pi - 1)
        quick_sort_inplace(arr, pi + 1, high)

def partition(arr, low, high):
    """分区函数"""
    pivot = arr[high]
    i = low - 1
    
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1

# 使用示例
arr = [64, 34, 25, 12, 22, 11, 90]
print("排序前:", arr)
sorted_arr = quick_sort(arr)
print("排序后:", sorted_arr)
```

- **时间复杂度**：平均 O(n log n)，最坏 O(n²)
- **空间复杂度**：O(log n) 递归栈
- **稳定性**：不稳定
- **适用场景**：大规模数据、平均性能最优

### 堆排序

#### 基本原理

堆排序利用堆的性质，先构建最大堆，然后逐个提取最大元素。

#### 堆排序实现

```python
def heap_sort(arr):
    """堆排序"""
    n = len(arr)
    
    # 构建最大堆
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)
    
    # 逐个提取元素
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]
        heapify(arr, i, 0)
    
    return arr

def heapify(arr, n, i):
    """堆化操作"""
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2
    
    if left < n and arr[left] > arr[largest]:
        largest = left
    
    if right < n and arr[right] > arr[largest]:
        largest = right
    
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)

# 使用示例

```

## 非比较排序算法

### 计数排序

#### 基本原理

计数排序统计每个元素出现的次数，根据统计结果重新排列元素。

#### 计数排序实现

```python
def counting_sort(arr):
    """计数排序"""
    if not arr:
        return []
    
    max_val = max(arr)
    min_val = min(arr)
    range_of_elements = max_val - min_val + 1
    
    # 创建计数数组
    count = [0] * range_of_elements
    
    # 统计每个元素出现的次数
    for num in arr:
        count[num - min_val] += 1
    
    # 重建排序后的数组
    sorted_arr = []
    for i in range(range_of_elements):
        sorted_arr.extend([i + min_val] * count[i])
    
    return sorted_arr

# 使用示例

print("排序后:", sorted_arr)
```

- **时间复杂度**：O(n + k)，k 是数据范围
- **空间复杂度**：O(k)
- **稳定性**：稳定
- **适用场景**：整数排序、数据范围有限

### 桶排序

#### 基本原理

桶排序将数据分到有限数量的桶中，每个桶单独排序，最后合并。

#### 桶排序实现

```python
def bucket_sort(arr):
    """桶排序"""
    if not arr:
        return []
    
    # 确定桶的数量
    num_buckets = len(arr)
    max_val = max(arr)
    min_val = min(arr)
    
    # 创建桶
    buckets = [[] for _ in range(num_buckets)]
    
    # 将元素分配到桶中
    for num in arr:
        index = int((num - min_val) / (max_val - min_val + 1) * num_buckets)
        buckets[index].append(num)
    
    # 对每个桶进行排序
    for bucket in buckets:
        bucket.sort()
    
    # 合并桶
    sorted_arr = []
    for bucket in buckets:
        sorted_arr.extend(bucket)
    
    return sorted_arr

# 使用示例

```

- **时间复杂度**：平均 O(n + k)，最坏 O(n²)

- **稳定性**：稳定
- **适用场景**：数据均匀分布

```python
def counting_sort_by_digit(arr, exp):
    """按位数进行计数排序"""
    n = len(arr)
    output = [0] * n
    count = [0] * 10
    
    # 统计当前位数的出现次数
    for i in range(n):
        index = (arr[i] // exp) % 10
        count[index] += 1
    
    # 计算累积计数
    for i in range(1, 10):
        count[i] += count[i - 1]
    
    # 构建输出数组
    for i in range(n - 1, -1, -1):
        index = (arr[i] // exp) % 10
        output[count[index] - 1] = arr[i]
        count[index] -= 1
    
    # 复制到原数组
    for i in range(n):
        arr[i] = output[i]

# 使用示例
arr = [170, 45, 75, 90, 802, 24, 2, 66]
print("排序前:", arr)
radix_sort(arr)
print("排序后:", arr)
```

```python
    """查找第K大元素"""
    # 使用快速选择算法
    def quick_select(left, right, k_smallest):
        if left == right:
            return arr[left]
        
        pivot_index = partition(left, right)
        
        if k_smallest == pivot_index:
            return arr[k_smallest]
        elif k_smallest < pivot_index:
            return quick_select(left, pivot_index - 1, k_smallest)
        else:
            return quick_select(pivot_index + 1, right, k_smallest)

        pivot = arr[right]
        i = left
        
        for j in range(left, right):
            if arr[j] <= pivot:
                arr[i], arr[j] = arr[j], arr[i]
                i += 1
        
        arr[i], arr[right] = arr[right], arr[i]
        return i
    
    return quick_select(0, len(arr) - 1, len(arr) - k)
```

## 动态规划

### 什么是动态规划

动态规划是一种通过将复杂问题分解为更简单的子问题来解决问题的方法。它存储子问题的解，避免重复计算，从而提高效率。

### 动态规划的核心思想

1. **最优子结构**：问题的最优解包含子问题的最优解
2. **重叠子问题**：子问题会被重复计算
3. **状态转移方程**：定义如何从子问题的解构造原问题的解
4. **边界条件**：定义问题的基本情况

### 动态规划的基本步骤

1. **定义状态**：确定需要存储的子问题解
2. **建立状态转移方程**：描述状态之间的关系
3. **确定边界条件**：定义初始状态
4. **计算顺序**：确定计算状态的顺序
5. **返回结果**：从存储的状态中获取答案

#### 0-1背包问题

```python
def knapsack_01(weights, values, capacity):
    """0-1背包问题"""
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        for w in range(1, capacity + 1):
            if weights[i - 1] <= w:
                dp[i][w] = max(
                    dp[i - 1][w],
                    dp[i - 1][w - weights[i - 1]] + values[i - 1]
                )
            else:
                dp[i][w] = dp[i - 1][w]
    
    return dp[n][capacity]

# 空间优化版本
def knapsack_01_optimized(weights, values, capacity):
    """空间优化的0-1背包问题"""
    n = len(weights)
    dp = [0] * (capacity + 1)
    
    for i in range(n):
        for w in range(capacity, weights[i] - 1, -1):
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
    
    return dp[capacity]
```

## 贪心算法

### 什么是贪心算法

贪心算法在每一步选择中都采取当前状态下最优（局部最优）的选择，希望通过局部最优选择达到全局最优。

### 贪心算法的特点

1. **贪心选择性质**：每一步选择局部最优解
2. **最优子结构**：问题的最优解包含子问题的最优解
3. **无后效性**：当前选择不影响后续选择

```python
    coins.sort(reverse=True)

            remaining -= num_coins * coin
```

```python
    """分数背包问题"""
    n = len(weights)
    items = [(values[i] / weights[i], weights[i], values[i]) for i in range(n)]
    items.sort(reverse=True, key=lambda x: x[0])
```

### 哈夫曼编码

```python
import heapq

class HuffmanNode:
    def __init__(self, char=None, freq=0, left=None, right=None):
        self.char = char
        self.freq = freq
        self.left = left
        self.right = right
    
    def __lt__(self, other):
        return self.freq < other.freq

def huffman_encoding(text):
    """哈夫曼编码"""
    if not text:
        return {}, ""
    
    # 统计字符频率
    freq = {}
    for char in text:
        freq[char] = freq.get(char, 0) + 1
    
    # 创建优先队列
    heap = [HuffmanNode(char, f) for char, f in freq.items()]
    heapq.heapify(heap)
    
    # 构建哈夫曼树
    while len(heap) > 1:
        left = heapq.heappop(heap)
        right = heapq.heappop(heap)
        merged = HuffmanNode(freq=left.freq + right.freq, left=left, right=right)
        heapq.heappush(heap, merged)
    
    # 生成编码
    codes = {}
    
    def generate_codes(node, current_code=""):
        if node is None:
            return
        
        if node.char is not None:
            codes[node.char] = current_code
            return
        
        generate_codes(node.left, current_code + "0")
        generate_codes(node.right, current_code + "1")
    
    generate_codes(heap[0])
    
    # 编码文本
    encoded_text = "".join(codes[char] for char in text)
    
    return codes, encoded_text

# 使用示例
text = "hello world"

print("哈夫曼编码:", codes)
print("编码结果:", encoded)
```

## 回溯算法

### 什么是回溯算法

回溯算法是一种通过探索所有可能的候选解来找出所有解的算法。当候选解被确认不是一个解（或者至少不是最后一个解）时，回溯算法会通过在上一步进行一些变化丢弃该解，即"回溯"并再次尝试。

### 回溯算法的特点

1. **系统性搜索**：系统地搜索解空间
2. **深度优先搜索**：通常使用DFS实现
3. **剪枝优化**：及时放弃不可能的解
4. **递归实现**：通常使用递归来实现

### N皇后问题

```python
def solve_n_queens(n):
    """N皇后问题"""
    def is_safe(board, row, col):
        # 检查列
        for i in range(row):
            if board[i] == col:
                return False
        
        # 检查对角线
        for i in range(row):
            if abs(board[i] - col) == abs(i - row):
                return False
        
        return True
    
    def backtrack(board, row):
        if row == n:
            solutions.append(board.copy())
            return
        
        for col in range(n):
            if is_safe(board, row, col):
                board[row] = col
                backtrack(board, row + 1)
                board[row] = -1
    
    solutions = []
    board = [-1] * n
    backtrack(board, 0)
    
    return solutions

# 使用示例
```

```python
        if start == len(nums):
            result.append(nums.copy())
```

```python
def solve_sudoku(board):
    """数独求解"""
    def is_valid(row, col, num):
        # 检查行
        for i in range(9):
            if board[row][i] == num:
                return False
        
        # 检查列
        for i in range(9):
            if board[i][col] == num:
                return False
        
        # 检查3x3宫格
        box_row, box_col = 3 * (row // 3), 3 * (col // 3)
        for i in range(3):
            for j in range(3):
                if board[box_row + i][box_col + j] == num:
                    return False
        
        return True

        for row in range(9):
            for col in range(9):
                if board[row][col] == 0:
                    for num in range(1, 10):
                        if is_valid(row, col, num):
                            board[row][col] = num
                            if solve():
                                return True
                            board[row][col] = 0
                    return False
        return True
    
    solve()
    return board
```

### 回溯算法的优化

#### 剪枝

```python
def combination_sum(candidates, target):
    """组合总和（带剪枝）"""
    def backtrack(start, current, remaining):
        if remaining == 0:
            result.append(current.copy())
            return
        elif remaining < 0:
            return
        
        for i in range(start, len(candidates)):
            # 剪枝：如果当前数字已经超过剩余目标，后续数字更大，无需尝试
            if candidates[i] > remaining:
                break
            
            current.append(candidates[i])
            backtrack(i, current, remaining - candidates[i])
            current.pop()
    
    candidates.sort()  # 排序以便剪枝
    result = []
    backtrack(0, [], target)
    return result

# 使用示例
print(combination_sum([2, 3, 6, 7], 7))  # [[2, 2, 3], [7]]
```

## 算法选择策略

### 何时使用动态规划

- 问题具有最优子结构
- 子问题重叠
- 需要最优解而非任意解
- 可以定义清晰的状态转移方程

### 何时使用贪心算法

- 问题具有贪心选择性质
- 局部最优选择能导致全局最优
- 对解的精度要求不高
- 需要快速得到近似解

### 何时使用回溯算法

- 需要找出所有解
- 解空间可以通过系统搜索找到
- 问题规模适中
- 可以通过剪枝优化搜索

```python
def edit_distance(word1, word2):
    """编辑距离（动态规划）"""
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    # 初始化边界条件
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    
    # 填充DP表
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = min(
                    dp[i - 1][j] + 1,      # 删除
                    dp[i][j - 1] + 1,      # 插入
                    dp[i - 1][j - 1] + 1   # 替换
                )
    
    return dp[m][n]

# 使用示例
print(edit_distance("horse", "ros"))  # 3
print(edit_distance("intention", "execution"))  # 5
```

### 应用2：任务调度

```python
def task_scheduling(tasks, cooldown):
    """任务调度（贪心算法）"""
    from collections import Counter
    
    # 统计任务频率
    freq = Counter(tasks)
    # 按频率排序
    sorted_tasks = sorted(freq.keys(), key=lambda x: -freq[x])
    
    # 计算最短时间
    max_freq = freq[sorted_tasks[0]]
    idle_slots = (max_freq - 1) * cooldown
    
    for task in sorted_tasks[1:]:
        idle_slots -= min(max_freq - 1, freq[task])
    
    idle_slots = max(0, idle_slots)
    return len(tasks) + idle_slots

# 使用示例
tasks = ["A", "A", "A", "B", "B", "B"]
cooldown = 2
print(task_scheduling(tasks, cooldown))  # 8
```

```python
def graph_coloring(graph, colors):
    """图着色（回溯算法）"""
    def is_safe(vertex, color):
        for neighbor in graph[vertex]:
            if color_assignment[neighbor] == color:
                return False
        return True
    
    def backtrack(vertex):
        if vertex == len(graph):
            return True
        
        for color in range(1, colors + 1):
            if is_safe(vertex, color):
                color_assignment[vertex] = color
                if backtrack(vertex + 1):
                    return True
                color_assignment[vertex] = 0
        
        return False
    
    color_assignment = {v: 0 for v in graph}
    if backtrack(0):
        return color_assignment
    return None

# 使用示例
graph = {
    0: [1, 2, 3],
    1: [0, 2],
    2: [0, 1, 3],
    3: [0, 2]
}
colors = 3
result = graph_coloring(graph, colors)
print("着色方案:", result)
```

## 13.1 复杂度增长趋势

复杂度分析的关键不是计算某台电脑上的具体运行时间，而是观察输入规模变大后，算法成本的增长趋势。原书已经介绍了常见时间复杂度，本强化版建议读者重点记住：`O(log n)` 通常来自“每次缩小一半”，`O(n)` 通常来自“一次遍历”，`O(n²)` 通常来自“两层嵌套遍历”。

![常见复杂度增长趋势](figures/02_complexity_growth.svg)

## 13.2 二分查找执行过程

二分查找适用于有序数组。它每次取中间位置 `mid`，通过比较 `arr[mid]` 与目标值，把搜索区间缩小到左半区或右半区。

![二分查找执行过程](figures/enhanced_binary_search_steps.svg)

核心变量：

- `left`：当前搜索区间左边界。
- `right`：当前搜索区间右边界。
- `mid`：当前比较位置。
- 循环条件：`left <= right`。

容易出错的地方：

1. `mid = (left + right) // 2` 在部分语言中可能溢出，可写成 `left + (right - left) // 2`。
2. 更新区间时，若已经比较过 `mid`，下一轮应排除它，即 `right = mid - 1` 或 `left = mid + 1`。
3. 二分查找要求数据有序，否则结果没有意义。

## 13.3 冒泡排序执行过程

冒泡排序每一轮都比较相邻元素，如果前一个比后一个大，就交换。每轮结束后，当前未排序区间中的最大值会移动到右侧。

![冒泡排序执行过程](figures/enhanced_bubble_sort_passes.svg)

优化点：如果某一轮没有发生任何交换，说明数组已经有序，可以提前结束。

## 13.4 快速排序分区过程

快速排序的关键在于“分区”：选取一个基准值 `pivot`，把小于它的元素放到一侧，大于它的元素放到另一侧。分区完成后，`pivot` 所在位置就是它最终排序后的位置。

![快速排序分区过程](figures/enhanced_quick_sort_partition.svg)

学习重点：

- 快速排序不是简单交换，而是在不断“确定一个元素的最终位置”。
- 分区质量决定效率。如果每次都极不均衡，会退化到 `O(n²)`。
- 实战中常用随机化基准、三数取中、三路快排来降低退化风险。

## 13.5 归并排序执行过程

归并排序采用分治思想：先把大问题不断拆成小问题，再把有序小数组合并成大数组。

![归并排序执行过程](figures/enhanced_merge_sort_process.svg)

它的优势是时间复杂度稳定为 `O(n log n)`，并且是稳定排序；缺点是需要额外空间。

## 13.6 栈与队列执行过程

栈和队列都是线性结构，但它们限制了元素进出的方式。栈是后进先出，队列是先进先出。

常见应用：

- 队列：广度优先搜索、任务调度、消息队列、打印队列。

## 14.5 BFS 图搜索

### Python

```python
from collections import deque

def bfs(graph, start):
    visited = set([start])
    q = deque([start])
    order = []
    while q:
        node = q.popleft()
        order.append(node)
        for nxt in graph[node]:
            if nxt not in visited:
                visited.add(nxt)
                q.append(nxt)
    return order
```

## 14.7 归并排序

### Python

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    i = j = 0
    result = []
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i]); i += 1
        else:
            result.append(right[j]); j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

```cpp
void mergeSort(vector<int>& a, int l, int r) {

    mergeSort(a, m + 1, r);

        else tmp.push_back(a[j++]);
```

## 14.8 0-1背包

```python
def knapsack_01(weights, values, capacity):
    dp = [0] * (capacity + 1)
    for wgt, val in zip(weights, values):
        for c in range(capacity, wgt - 1, -1):
            dp[c] = max(dp[c], dp[c - wgt] + val)
    return dp[capacity]
```

## 14.9 并查集

### Python

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        if self.rank[ra] == self.rank[rb]:
            self.rank[ra] += 1
        return True
```

### C++

```cpp
class UnionFind {
private:
    vector<int> parent, rankv;
public:
    UnionFind(int n) : parent(n), rankv(n, 0) {
        for (int i = 0; i < n; ++i) parent[i] = i;
    }
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }
    bool unite(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        if (rankv[ra] < rankv[rb]) swap(ra, rb);
        parent[rb] = ra;
        if (rankv[ra] == rankv[rb]) rankv[ra]++;
        return true;
    }
};
```

## 17.7 图练习

### 题1：判断无向图是否连通

**答案：** 从任意点 BFS/DFS，如果访问节点数量等于总节点数，则连通。

```python
from collections import deque

def is_connected(graph):
    if not graph:
        return True
    start = next(iter(graph))
    visited = set([start])
    q = deque([start])
    while q:
        u = q.popleft()
        for v in graph[u]:
            if v not in visited:
                visited.add(v)
                q.append(v)
    return len(visited) == len(graph)
```

### 题2：无权图最短路径

**答案：** 使用 BFS。

```python
def shortest_path_unweighted(graph, start, target):
    from collections import deque
    q = deque([(start, 0)])
    visited = {start}
    while q:
        node, dist = q.popleft()
        if node == target:
            return dist
        for nxt in graph[node]:
            if nxt not in visited:
                visited.add(nxt)
                q.append((nxt, dist + 1))
    return -1
```

### 题3：最长公共子序列

**答案：**

```python
def lcs(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]
```

## 17.12 回溯算法练习

### 题1：全排列

**答案：**

```python
def permute(nums):
    res = []
    used = [False] * len(nums)

    def backtrack(path):
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i, x in enumerate(nums):
            if used[i]:
                continue
            used[i] = True
            path.append(x)
            backtrack(path)
            path.pop()
            used[i] = False

    backtrack([])
    return res
```

```python
def combine(n, k):

        if len(path) == k:
            res.append(path[:])

            path.append(x)
            backtrack(x + 1, path)
            path.pop()

    return res
```
